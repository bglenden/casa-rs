§casa-flagging

Calculate, write, and manage visibility flags in MeasurementSets.

§Main types

  • FlagDataRequest — Visibility selection, flagging agent, and requested action.
  • FlagDataMode — A flagging algorithm or summary request.
  • FlagDataAction — Whether to calculate or apply flags.
  • FlagVersionEntry — A named saved set of flags and its comment.

Build a request to clear manual flags on the selected data.

use casa_flagging::{FlagDataAction, FlagDataMode, FlagDataRequest};

let request = FlagDataRequest {
    action: FlagDataAction::Unflag,
    ..FlagDataRequest::default()
};
assert!(matches!(request.mode, FlagDataMode::Manual));

flagdata_calibration_program
Execute a sequence of calibration flagging agents on one table view. Earlier commands are visible to subsequent agents and summaries. A calculate-only run discards its staged flags, and an apply run saves the combined changed rows after all commands have completed. An entry is absent when CASA cannot configure that agent and continues the program. With multiple commands, selection is local to each agent and a time range gates the calibration buffers at their first integration. Use the same cancellation token for the program’s requests.
flagdata_ms_program
Execute a sequence of MeasurementSet flagging agents on one opened table view. Earlier agents’ staged edits are visible to later summary and propagation passes. CASA’s antenna-integration prepass reads the original input flags. When write_flags is false, staged flags are discarded without mutating the MeasurementSet on disk; when true, changed rows are written once at the end. When local_selection is true (multiple commands in CASA’s mode='list'), an agent whose local selection fails is skipped (None) rather than aborting the list; single-command runs propagate selection errors. Use the same cancellation token for the program’s requests.
