2//! CASA's MeasurementSet spectral-window and channel selection: the `spw`
3//! expressions of casacore's `MSSelection`, ported from `MSSpwGram.ll`,
4//! `MSSpwGram.yy`, `MSSpwParse.cc` and `MSSpwIndex.cc` at casacore
5//! `aaf72eb7`, the commit CASA 6.7.6.14 builds.
6//!
7//! [`resolve_spw_selector`] resolves an expression against the
8//! SPECTRAL_WINDOW rows ([`SpectralWindowRow`]) and the DATA_DESCRIPTION
9//! rows ([`DataDescriptionRow`]) into a [`SpwSelection`] holding what
10//! `MSSelection` reports for it: the windows (`getSpwList`), their data
11//! descriptions (`getSPWDDIDList`), the channel list (`getChanList`, from
12//! which `getChanFreqList` and `getChanSlices` follow) and the data
13//! descriptions whose MAIN rows the selection keeps.
14//! [`MeasurementSet::resolve_spw_selector`] reads those rows from a
15//! MeasurementSet.
16//!
17//! # Forms
18//!
19//! An expression is a comma-separated list of window terms, each optionally
20//! followed by `:` and a channel list; `( ... )` around the whole list is
21//! also accepted (see [Quirks](#casa-quirks-this-port-keeps)). A window term
22//! is one of:
23//!
24//! | Form | Windows | C++ |
25//! |---|---|---|
26//! | `3`, `1.7` | window 3, window 1 (numbers are truncated) | `MSSpwGram.yy:219-224, 393-408` |
27//! | `0~3`, `0~9^3`, `^2` | the indices `0..=3`, every third, and `-1` (no window) | `.yy:182-203`, `MSSpwIndex.cc:641-688` |
28//! | `0;2;5` | a `;` list of the above | `.yy:247-265` |
29//! | `name` | the windows whose NAME is exactly `name` (letters, digits, `_`, `'`, `{`, `}`, `+`, `#`, not starting with a digit) | `.ll:69-72, 158-164`, `.yy:267-284` |
30//! | `spw*`, `"any text*"`, `/text/` | the windows whose whole NAME the shell-style pattern matches (`*`, `?`, `[...]`, `{a,b}`); `/.../` is a pattern too, not a regex | `.ll:61-117, 165-171`, `MSSpwIndex.cc:55-75` |
31//! | `1.4GHz` | the first window whose midpoint is within its largest signed CHAN_WIDTH of 1.4 GHz | `MSSpwIndex.cc:210-309` |
32//! | `1GHz~2GHz`, `1~2GHz` | the windows whose midpoint lies in the range | same |
33//! | `1GHz~2GHz^10MHz` | the windows one step of the range falls within the largest signed CHAN_WIDTH of | same |
34//! | `~1.4GHz` | the windows whose midpoint is within their TOTAL_BANDWIDTH of 1.4 GHz | same |
35//! | `>2`, `<2`, `2<>5` | identifiers above 2, below 2, strictly between | `MSSpwIndex.cc:344-371` |
36//! | `>50GHz`, `<50GHz`, `1GHz<>60GHz` | REF_FREQUENCY above, below, strictly between | `MSSpwIndex.cc:313-340` |
37//!
38//! A window's midpoint is the single-precision mean of its first and last
39//! CHAN_FREQ; all frequencies in an expression are single precision, as in
40//! the C++. Frequency units are `Hz`, `kHz`, `MHz`, `GHz` and `THz` in any
41//! case, chosen by the first letter (`mHz` is a megahertz); velocity units
42//! (`km/s`, `m/s`) are refused, as CASA disables them
43//! (`MSSpwGram.yy:117-134`).
44//!
45//! A channel list is a `;` list of:
46//!
47//! | Form | Channels (`[start, stop, step]` in [`SpwSelection::channel_list`]) | C++ |
48//! |---|---|---|
49//! | `5` | `[5, 5, 1]`; past the end, the last channel (logged) | `MSSpwIndex.cc:421-463` |
50//! | `2~9`, `2~9^2` | `[2, 9, 1]`, `[2, 9, 2]`; each end clamped to the window (logged when the stop is past it) | same |
51//! | `^3` | `[0, last, 3]` | `.yy:196-202` |
52//! | `-1`, `-1~5` | `-1` is the first (as a start) or last (as a stop) channel: `-1` alone is every channel | same |
53//! | `1.40GHz~1.41GHz` | the first channel centre at or above the start to the last at or below the stop, `-1` where there is none; the step in hertz over the largest signed CHAN_WIDTH | `MSSpwIndex.cc:464-536, 593-637` |
54//! | `1.4GHz` | the channels bracketing 1.4 GHz | same |
55//!
56//! A step below 1 is 1; a range whose start exceeds its stop, as written,
57//! is refused.
58//!
59//! # Refusals
60//!
61//! Besides syntax errors and reversed ranges, CASA refuses an expression
62//! when any window term matches nothing (a name, pattern, `>`/`<`/`<>`
63//! bound, or index naming no row): the "no match" reports go to the
64//! `MSSelectionErrorHandler`, which throws once parsing ends
65//! (`MSSelection.cc:859-883`). A frequency that matches no window throws at
66//! once (`MSSpwIndex.cc:298-307`). Without any window that has an
67//! unflagged data description, or without any channel range, the expression
68//! is refused (`MSSpwParse.cc:307-312`, `MSSpwGram.cc:121-123`).
69//!
70//! # CASA quirks this port keeps
71//!
72//! - An index past the last row is looked up as a NAME: in a 10-window
73//!   MeasurementSet whose window 4 is named `12`, `12` selects window 4,
74//!   while `7` is always window 7 (`MSSpwIndex.cc:82-98`).
75//! - A window's FLAG_ROW, and a data description's, remove the window from
76//!   [`spw_ids`](SpwSelection::spw_ids) and its rows, but not its channels
77//!   from [`channel_list`](SpwSelection::channel_list); a window without a
78//!   data description likewise (`MSSpwParse.cc:106-148`). A window with
79//!   two data descriptions is listed twice.
80//! - [`spw_ids`](SpwSelection::spw_ids), its data descriptions and the
81//!   channel list keep the expression's order and repeats.
82//! - A channel range in hertz reads the channel order from the sign of the
83//!   first CHAN_WIDTH, not from the frequencies, and divides its step by the
84//!   largest *signed* width; one frequency selects the channels on either
85//!   side of it.
86//! - A single window frequency compares with the largest *signed*
87//!   CHAN_WIDTH, so it matches no window with negative widths.
88//! - When a window's first channel range in hertz finds no channel, the
89//!   next window takes its ranges from that window's second range on
90//!   (`MSSpwParse.cc:238-250`); ranges after the first may keep a start of
91//!   `-1`.
92//! - In a window list, a frequency replaces the list built so far but not
93//!   the write position, so an index after it overwrites from there and
94//!   pads with zeros (window 0): `100GHz~101GHz;0` lists the matched windows
95//!   and then 0 again (`MSSpwIndex.cc:641-688`).
96//! - `( ... )` skips the step that turns the windows into a row condition,
97//!   so the selection keeps every MAIN row ([`SpwSelection::rows_restricted`]
98//!   is false) while still listing the windows and channels.
99//! - Scanning follows flex: `"text` or `/text` without its closing quote
100//!   ends the expression (`0"x` is `0`); a backslash or newline inside quotes
101//!   is dropped; a byte from 0x80 up ends the expression (`0é` is `0`);
102//!   `-` is no name character, so `LBAND-A` must be quoted; `e5` and `+2`
103//!   are numbers; `Hz` and `MHz` are units, not names.
104//! - Out-of-range channels are logged, as CASA logs them, in
105//!   [`SpwSelection::warnings`].
106//!
107//! # Not ported
108//!
109//! - A number `sscanf("%f")` cannot read (`.`, `+`, `e5`), which CASA reads
110//!   as an uninitialised `Float`, and an index outside a C `Int`, whose cast
111//!   is undefined (x86 and ARM differ), are refused.
112//! - A stepped frequency search that CASA never leaves (a negative step on a
113//!   window whose least CHAN_WIDTH is negative, or a step too small to move a
114//!   single-precision frequency) is refused rather than run forever; one
115//!   longer than 2^27 steps is refused too.
116//! - A window list mixing frequencies and indices that CASA would write past
117//!   its end is refused.
118//! - Messages follow CASA's wording but not its character positions, and a
119//!   syntax error may be reported where CASA reports a name it looked up
120//!   before reaching it.
121//!
122//! # Evidence
123//!
124//! `resources/casa-compat/evidence/msselection-spw-casa-20261102.json` holds
125//! what CASA 6.7.6.14's `ms.msselect` and `ms.msselectedindices` report for
126//! 1552 expressions over two MeasurementSets (curated forms and seeded
127//! random ones), written by `tools/casa-compat/spw_selection_oracle.py`;
128//! `crates/casa-ms/tests/spw_selection_oracle.rs` replays every one.

141/// One SPECTRAL_WINDOW row as spectral-window selection reads it. In a slice
142/// of these, row `i` is window `i`.
143#[derive(Clone, Copy, Debug, PartialEq)]
144pub struct SpectralWindowRow<'a> {
145    /// NAME, compared exactly (case-sensitive, untrimmed).
146    pub name: &'a str,
147    /// CHAN_FREQ in hertz, in the column's own frame: CASA converts nothing.
148    /// Its length is the window's channel count (NUM_CHAN in a consistent
149    /// MeasurementSet).
150    pub chan_freq_hz: &'a [f64],
151    /// CHAN_WIDTH in hertz, signed.
152    pub chan_width_hz: &'a [f64],
153    /// REF_FREQUENCY in hertz, which `>`, `<` and `<>` with a unit compare.
154    pub ref_frequency_hz: f64,
155    /// TOTAL_BANDWIDTH in hertz, which `~f` compares.
156    pub total_bandwidth_hz: f64,
157    /// FLAG_ROW.
158    pub flag_row: bool,
159}

171/// One row of `MSSelection::getChanList()`: a window and an inclusive
172/// channel range with a step.
173///
174/// `start` is `-1` only in CASA's quirk of a later frequency range that
175/// found no channel (see the [module documentation](self)); otherwise
176/// `0 <= start <= stop < channels` and `step >= 1`.
177#[derive(Clone, Copy, Debug, PartialEq, Eq)]
178pub struct ChannelRange {
179    /// The SPECTRAL_WINDOW row.
180    pub spw_id: usize,
181    /// The first channel.
182    pub start: i32,
183    /// The last channel, inclusive.
184    pub stop: i32,
185    /// The channel step.
186    pub step: i32,
187}
188
189impl ChannelRange {
190    /// The channels the range selects, as `MSSelection::getChanSlices`
191    /// slices them: `start, start + step, ...` up to `stop`. `None` for a
192    /// range starting at `-1`.
193    #[must_use]
194    pub fn channels(&self) -> Option<impl Iterator<Item = usize> + use<>> {
195        let start = usize::try_from(self.start).ok()?;
196        let stop = usize::try_from(self.stop)
197            .ok()
198            .filter(|&stop| stop >= start);
199        let step = usize::try_from(self.step).unwrap_or(1).max(1);
200        Some(
201            stop.into_iter()
202                .flat_map(move |stop| (start..=stop).step_by(step)),
203        )
204    }
205}

221/// A resolved `spw` expression: what `MSSelection` reports for it.
222#[derive(Clone, Debug, Default, PartialEq, Eq)]
223pub struct SpwSelection {
224    selects_all: bool,
225    spw_ids: Box<[usize]>,
226    data_description_ids: Box<[usize]>,
227    channels: Box<[ChannelRange]>,
228    rows: Option<Box<[usize]>>,
229    warnings: Box<[String]>,
230}
231
232impl SpwSelection {
233    /// The selection of the empty expression, which `MSSelection` skips:
234    /// no condition on rows and no lists.
235    #[must_use]
236    pub fn all() -> Self {
237        Self {
238            selects_all: true,
239            ..Self::default()
240        }
241    }
242
243    /// Whether the expression was empty.
244    #[must_use]
245    pub fn selects_all(&self) -> bool {
246        self.selects_all
247    }
248
249    /// `MSSelection::getSpwList()`: each selected window once per unflagged
250    /// data description of it, in the expression's order with repeats;
251    /// flagged windows and windows without a data description are absent.
252    #[must_use]
253    pub fn spw_ids(&self) -> &[usize] {
254        &self.spw_ids
255    }
256
257    /// `MSSelection::getSPWDDIDList()`: the data description of each entry
258    /// of [`spw_ids`](Self::spw_ids).
259    #[must_use]
260    pub fn data_description_ids(&self) -> &[usize] {
261        &self.data_description_ids
262    }
263
264    /// `MSSelection::getChanList()` (unsorted, default step 1): one range
265    /// per window and channel element, in the expression's order.
266    #[must_use]
267    pub fn channel_list(&self) -> &[ChannelRange] {
268        &self.channels
269    }
270
271    /// Whether the selection restricts MAIN rows by `DATA_DESC_ID`: false
272    /// for the empty expression and for a parenthesized one.
273    #[must_use]
274    pub fn rows_restricted(&self) -> bool {
275        self.rows.is_some()
276    }
277
278    /// The data descriptions whose MAIN rows are selected, ascending, or
279    /// `None` when every row is ([`rows_restricted`](Self::rows_restricted)
280    /// is false).
281    #[must_use]
282    pub fn row_data_descriptions(&self) -> Option<&[usize]> {
283        self.rows.as_deref()
284    }
285
286    /// Whether a MAIN row with this `DATA_DESC_ID` is selected.
287    #[must_use]
288    pub fn selects_row(&self, data_desc_id: i32) -> bool {
289        self.rows.as_ref().is_none_or(|rows| {
290            usize::try_from(data_desc_id).is_ok_and(|ddid| rows.binary_search(&ddid).is_ok())
291        })
292    }
293
294    /// The channels of window `spw_id` its channel ranges select, ascending
295    /// and each once, or `None` when no range names the window.
296    ///
297    /// # Errors
298    ///
299    /// A range of the window starting at `-1`, where CASA's channel slices
300    /// are undefined.
301    pub fn channels_of(&self, spw_id: usize) -> MsResult<Option<Vec<usize>>> {
302        let mut channels = Vec::new();
303        let mut named = false;
304        for range in self.channels.iter().filter(|range| range.spw_id == spw_id) {
305            named = true;
306            channels.extend(range.channels().ok_or_else(|| {
307                MsError::InvalidInput(format!(
308                    "spw selection: window {spw_id}'s channel range {}~{} starts before its \
309                     first channel",
310                    range.start, range.stop
311                ))
312            })?);
313        }
314        channels.sort_unstable();
315        channels.dedup();
316        Ok(named.then_some(channels))
317    }
318
319    /// `MSSelection::getChanFreqList()` (unsorted): each channel range's
320    /// first and last CHAN_FREQ and its step times the window's mean
321    /// CHAN_WIDTH, `step * sum(widths) / n` (`MSSelection.cc:1330-1363`).
322    ///
323    /// # Errors
324    ///
325    /// A range outside its window in `windows`, which must be the rows the
326    /// selection was resolved against.
327    pub fn channel_frequency_list(
328        &self,
329        windows: &[SpectralWindowRow<'_>],
330    ) -> MsResult<Vec<ChannelFrequencyRange>> {
331        self.channels
332            .iter()
333            .map(|range| {
334                let window = windows.get(range.spw_id);
335                let frequency = |channel: i32| {
336                    usize::try_from(channel)
337                        .ok()
338                        .and_then(|channel| window?.chan_freq_hz.get(channel).copied())
339                };
340                let (Some(window), Some(start_hz), Some(stop_hz)) =
341                    (window, frequency(range.start), frequency(range.stop))
342                else {
343                    return Err(MsError::InvalidInput(format!(
344                        "spw selection: channel range {range:?} is outside its window"
345                    )));
346                };
347                let sum: f64 = window.chan_width_hz.iter().sum();
348                Ok(ChannelFrequencyRange {
349                    spw_id: range.spw_id,
350                    start_hz,
351                    stop_hz,
352                    step_hz: f64::from(range.step) * sum / window.chan_width_hz.len() as f64,
353                })
354            })
355            .collect()
356    }
357
358    /// What CASA logs at `WARN` while resolving the expression: channels
359    /// clamped to their window, frequency ranges that find no channel, and
360    /// non-constant channel widths, worded as CASA words them (messages of
361    /// one window list accumulate, as CASA's do).
362    #[must_use]
363    pub fn warnings(&self) -> &[String] {
364        &self.warnings
365    }
366
367    /// The heap bytes the selection owns: its lists and warning text.
368    #[must_use]
369    pub fn allocated_bytes(&self) -> usize {
370        size_of_val::<[usize]>(&self.spw_ids)
371            + size_of_val::<[usize]>(&self.data_description_ids)
372            + size_of_val::<[ChannelRange]>(&self.channels)
373            + self.rows.as_deref().map_or(0, size_of_val::<[usize]>)
374            + size_of_val::<[String]>(&self.warnings)
375            + self.warnings.iter().map(String::capacity).sum::<usize>()
376    }
377}

379/// Resolve CASA spectral-window selection `text` against `windows`, the
380/// SPECTRAL_WINDOW rows, and `descriptions`, the DATA_DESCRIPTION rows, in
381/// row order. See the [module documentation](self) for the forms.
382///
383/// The empty string selects everything ([`SpwSelection::all`]), as
384/// `MSSelection` skips an empty expression; text of only blanks is a syntax
385/// error.
386///
387/// # Errors
388///
389/// [`MsError::InvalidInput`], worded as CASA's `MSSelectionSpwError`, for
390/// any expression CASA refuses (see [Refusals](self#refusals)) and for the
391/// cases listed under [Not ported](self#not-ported).
392pub fn resolve_spw_selector(
393    windows: &[SpectralWindowRow<'_>],
394    descriptions: &[DataDescriptionRow],
395    text: &str,
396) -> MsResult<SpwSelection> {
397    if text.is_empty() {
398        return Ok(SpwSelection::all());
399    }
400    let refuse =
401        |message: String| MsError::InvalidInput(format!("spw selection {text:?}: {message}"));
402    let expression = grammar::parse(text).map_err(refuse)?;
403    let resolved = actions::resolve(&expression, windows, descriptions).map_err(refuse)?;
404    Ok(SpwSelection {
405        selects_all: false,
406        spw_ids: resolved.spw_ids.into_boxed_slice(),
407        data_description_ids: resolved.data_description_ids.into_boxed_slice(),
408        channels: resolved.channels.into_boxed_slice(),
409        rows: resolved.rows.map(Vec::into_boxed_slice),
410        warnings: resolved.warnings.into_boxed_slice(),
411    })
412}

414/// The SPECTRAL_WINDOW columns spectral-window selection reads, owned.
415struct OwnedWindow {
416    name: String,
417    chan_freq_hz: Vec<f64>,
418    chan_width_hz: Vec<f64>,
419    ref_frequency_hz: f64,
420    total_bandwidth_hz: f64,
421    flag_row: bool,
422}
423
424impl MeasurementSet {
425    /// Resolve CASA spectral-window selection `text` against this
426    /// MeasurementSet's SPECTRAL_WINDOW (NAME, CHAN_FREQ, CHAN_WIDTH,
427    /// REF_FREQUENCY, TOTAL_BANDWIDTH, FLAG_ROW) and DATA_DESCRIPTION
428    /// (SPECTRAL_WINDOW_ID, FLAG_ROW) tables, as [`resolve_spw_selector`]
429    /// does over rows a caller supplies.
430    ///
431    /// Reads only those two subtables; MAIN is not scanned.
432    ///
433    /// # Errors
434    ///
435    /// An unreadable subtable, or any refusal of [`resolve_spw_selector`].
436    pub fn resolve_spw_selector(&self, text: &str) -> MsResult<SpwSelection> {
437        if text.is_empty() {
438            return Ok(SpwSelection::all());
439        }
440        let table = self.spectral_window()?;
441        let owned = (0..table.row_count())
442            .map(|row| {
443                Ok(OwnedWindow {
444                    name: table.name(row)?,
445                    chan_freq_hz: table.chan_freq(row)?,
446                    chan_width_hz: table.chan_width(row)?,
447                    ref_frequency_hz: table.ref_frequency(row)?,
448                    total_bandwidth_hz: table.total_bandwidth(row)?,
449                    flag_row: table.flag_row(row)?,
450                })
451            })
452            .collect::<MsResult<Vec<_>>>()?;
453        let windows = owned
454            .iter()
455            .map(|window| SpectralWindowRow {
456                name: &window.name,
457                chan_freq_hz: &window.chan_freq_hz,
458                chan_width_hz: &window.chan_width_hz,
459                ref_frequency_hz: window.ref_frequency_hz,
460                total_bandwidth_hz: window.total_bandwidth_hz,
461                flag_row: window.flag_row,
462            })
463            .collect::<Vec<_>>();
464        let table = self.data_description()?;
465        let descriptions = (0..table.row_count())
466            .map(|row| {
467                Ok(DataDescriptionRow {
468                    spectral_window_id: table.spectral_window_id(row)?,
469                    flag_row: table.flag_row(row)?,
470                })
471            })
472            .collect::<MsResult<Vec<_>>>()?;
473        resolve_spw_selector(&windows, &descriptions, text)
474    }
