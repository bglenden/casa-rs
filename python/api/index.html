    ADR-0006 defines this common surface for task profiles; ADR-0012 defines the current-only option used by imager:

casars.tasks.run(task, parameters=None, /, *, workspace=None, **values)
casars.tasks.<casa_task>(casa_parameters..., *, casa_rs_controls...)
casars.tasks.<task>(**parameters)

    A task call starts the task's own executable. tasks.run returns a TaskCompletion (task, command, workspace, returncode, stdout, the reply; stderr, the log; provider_invocation, status, message, parameter, value, CASA's return value; and result, the declared products). A wrapper whose surface names its CASA task (the image tasks, flagdata, flagmanager, importvla, mstransform, split, applycal, gaincal, bandpass, fluxscale, gencal and simobserve so far) has CASA's signature, positional or by keyword with CASA's defaults, then casa-rs's own controls, keyword-only, and returns CASA's value, with NumPy arrays where CASA returns them. A parameter casa-rs does not implement yet is taken only at CASA's default; its docstring names the issue. The other wrappers take keyword arguments and return the TaskCompletion until their families are converted (#931).

    A value the contract refuses raises ValueError before anything starts, or TypeError for a value of the wrong type. A task that refuses its parameters raises TaskParameterError, a ValueError, and one that starts and does not succeed TaskExecutionError, a RuntimeError; the .completion of either says how it ended. TaskBinaryNotFoundError (a FileNotFoundError) names what the executable search lacked; TaskInvocationError means the process could not start; TaskResultError means a success's result was malformed.

    A Python task call saves no Last or Last Successful profile; those record command-line runs. The CASA-named wrappers take the surface's parameters. A profile runs through one as tasks.gaincal(**parameters.load(path)), since a draft, as a mapping, holds the parameters that have a value.

    TaskParameters (a SurfaceParameters constrained to a task definition) is mapping-like and retains value origins and validation diagnostics. Saving writes only required values and differences from current defaults. Surface definitions and defaults are read from the same Rust catalog that the task executables' command lines use.

    The catalog-driven generic runner and generated CASA-named functions are the only public task path. Generated conveniences live directly in casars.tasks; their checked .pyi file is regenerated from crates/casa-provider-contracts/resources/parameter-surfaces.json.

    class Image:
    """Persistent CASA-compatible image access.

    This wrapper exposes rectangular slice and plane I/O using native NumPy
    arrays while keeping the storage model file-backed and stateful. V1 write
    support is limited to pixel-slice updates on existing persistent images.
    Image creation and coordinate/metadata authoring are intentionally out of
    scope.
    """

    def __init__(self, inner: _core.Image) -> None:
        self._inner = inner

    @classmethod
    def open(cls, path: StrPath, *, writable: bool = False) -> "Image":
        """Open an existing persistent image.

        Set ``writable=True`` to enable pixel-slice updates with
        :meth:`put_slice`.
        """

        return cls(_core.Image.open(path, writable=writable))

    @property
    def shape(self) -> tuple[int, ...]:
        """Image shape in CASA/Rust axis order."""

        return tuple(self._inner.shape)

    @property
    def pixel_type(self) -> str:
        """Pixel dtype name such as ``float32`` or ``complex128``."""

        return self._inner.pixel_type

    @property
    def units(self) -> str:
        """Image unit string."""

        return self._inner.units

    @property
    def image_info(self) -> RecordLike:
        """Structured image-info record."""

        return self._inner.image_info

    @property
    def misc_info(self) -> RecordLike:
        """Structured miscellaneous-info record."""

        return self._inner.misc_info

    @property
    def coordinate_system(self) -> RecordLike:
        """Renderer-neutral coordinate metadata, including celestial WCS."""

        return self._inner.coordinate_system

    def _direction_wcs(self) -> tuple[int, int, dict[str, Any]] | None:
        """The pixel axes of the image's direction and the FITS WCS keywords
        `exportfits` writes for the image, or None; for `casars.imexplore`."""

        return self._inner._direction_wcs()

    @property
    def mask_names(self) -> list[str]:
        """Names of persisted masks attached to the image."""

        return list(self._inner.mask_names)

    @property
    def default_mask_name(self) -> str | None:
        """Name of the default mask, if any."""

        return self._inner.default_mask_name

    def get_slice(
        self,
        start: Sequence[int],
        shape: Sequence[int],
        *,
        stride: Sequence[int] | None = None,
    ) -> ArrayLike:
        """Read a rectangular image chunk as a NumPy array."""

        return self._inner.get_slice(list(start), list(shape), stride=None if stride is None else list(stride))

    def put_slice(self, data: ArrayLike, start: Sequence[int]) -> None:
        """Write a rectangular image chunk into an existing persistent image.

        This is the supported v1 write path for images. It does not imply
        support for Python-side image creation or coordinate/metadata editing.
        """

        self._inner.put_slice(np.asarray(data), list(start))

    def get_plane(self, axis: int, index: int) -> ArrayLike:
        """Read one plane orthogonal to ``axis``."""

        return np.squeeze(self._inner.get_plane(axis, index), axis=axis)

    def get_mask_slice(
        self,
        start: Sequence[int],
        shape: Sequence[int],
        *,
        stride: Sequence[int] | None = None,
    ) -> ArrayLike | None:
        """Read a rectangular chunk from the default mask."""

        return self._inner.get_mask_slice(
            list(start),
            list(shape),
            stride=None if stride is None else list(stride),
        )

    def __init__(self, inner: _core.Table) -> None:

    @classmethod
    def open(cls, path: StrPath, *, writable: bool = False) -> "Table":
        """Open an existing persistent table."""

        return cls(_core.Table.open(path, writable=writable))

    @property
    def row_count(self) -> int:
        """Number of rows in the table."""

        return self._inner.row_count

    @property
    def column_names(self) -> list[str]:
        """Known column names."""

        return list(self._inner.column_names)

    @property
    def keywords(self) -> RecordLike:
        """Table-level keyword record."""

        return self._inner.keywords

    def column_keywords(self, name: str) -> RecordLike | None:
        """Column-level keyword record for ``name``."""

        return self._inner.column_keywords(name)

    def get_cell(self, row: int, column: str) -> Any:
        """Read one cell."""

        return self._inner.get_cell(row, column)

    def set_cell(self, row: int, column: str, value: Any) -> None:
        """Write one cell."""

        self._inner.set_cell(row, column, value)

    def get_column(
        self,
        column: str,
        *,
        start: int = 0,
        count: int | None = None,
        step: int = 1,
    ) -> Any:
        """Read a column range as NumPy arrays or native Python structures."""

        return self._inner.get_column(column, start=start, count=count, step=step)

    def put_column(
        self,
        column: str,
        values: Sequence[Any],
        *,
        start: int = 0,
        step: int = 1,
    ) -> int:
        """Write a column range from Python-native values."""

        return self._inner.put_column(column, values, start=start, step=step)

    def set_column_keywords(self, column: str, keywords: Mapping[str, Any]) -> None:
        """Replace the keyword record for ``column``."""

        self._inner.set_column_keywords(column, dict(keywords))

class TaskCompletion:
    """One finished task process: how it ended and what it wrote.

    ``status`` is the task's outcome: ``succeeded``, ``refused`` (its
    parameters, before it changed anything), ``failed``, ``interrupted``,
    ``signalled``, or ``malformed_reply``. ``stdout`` is the task's reply and
    ``stderr`` its log, which was also written to ``sys.stderr`` as the task
    ran.
    """

    task: str
    command: tuple[str, ...]
    workspace: Path
    returncode: int
    stdout: str
    stderr: str
    provider_invocation: ProviderInvocation
    status: str
    message: str | None
    parameter: str | None
    value: Any
    result: object | None

    @property
    def successful(self) -> bool:
        """Whether the task succeeded."""

        return self.status == "succeeded"

    @property
    def products(self) -> tuple[object, ...]:
        """Typed contract-declared products from the Rust completion decoder."""

        if self.result is None:
            return ()
        return tuple(self.result.products)  # type: ignore[attr-defined]

    def describe(self) -> str:
        """One line saying how the task ended."""

        at = f" (parameter {self.parameter!r})" if self.parameter else ""
        if self.status == "succeeded":
            return f"{self.task} succeeded"
        if self.status == "refused":
            return f"{self.task} refused its parameters{at}: {self.message}"
        if self.status == "failed":
            return f"{self.task} failed{at}: {self.message}"
        if self.status == "interrupted":
            return f"{self.task} was interrupted: {self.message}"
        detail = self.stderr.strip().splitlines()[-1:] or ["no log output"]
        if self.status == "signalled":
            return f"{self.task} was ended by signal {-self.returncode}: {detail[0]}"
        return f"{self.task} gave no valid reply ({self.message}): {detail[0]}"

    def run(
    task: str,
    parameters: SurfaceParameters | None = None,
    /,
    *,
    workspace: StrPath | None = None,
    **values: ParameterData,
) -> TaskCompletion:
    """Run any catalog task, with CASA-named ``values``.

    ``parameters`` is a draft to start from, such as a loaded profile; the
    contract's defaults otherwise. The task runs in ``workspace``: the
    draft's, or the current directory. Values are normalized and checked by
    Rust before the task starts, so a value the contract refuses raises
    ``ValueError`` and starts nothing.

    The call loads and saves no Last profile: those record command-line runs.
    :meth:`TaskParameters.last` and :meth:`TaskParameters.write_last` stay
    explicit. CASA's own parameters, such as ``overwrite``, are the consent
    to replace or change data. A task that refuses its parameters raises
    :class:`TaskParameterError`, a ``ValueError``, and one that starts and
    does not succeed :class:`TaskExecutionError`, a ``RuntimeError``; an
    interrupt (Ctrl-C) is passed to the task, which is given time to stop,
    and then raised here.
    """

    resolved_workspace = _resolve_workspace(workspace, parameters)
    if parameters is not None:
        if parameters.surface != task:
            raise ValueError(
                f"parameters target {parameters.surface!r}, not requested task {task!r}"
            )
        resolved = parameters.copy()
    else:
        resolved = TaskParameters.defaults(task, workspace=resolved_workspace)
    if values:
        resolved.set_many(values)
    return _execute(task, resolved, resolved_workspace)

    casars.tools¶

    CASA tools for casa-rs, under CASA's class names (ADR-0019).

    from casars.tools import measures, quanta, simulator

me = measures()

    casars.simutil¶

    CASA's simutil helper class for casa-rs.

    A CASA script changes only its import::

    from casars import simutil

u = simutil.simutil()
x, y, z, d, padnames, antnames, telescope, posobs = u.readantenna("vla.d.cfg")
pointings = u.calc_pointings2("10arcsec", ["60arcsec", "40arcsec"], maptype="ALMA",
                              direction="J2000 18h00m00 -23d00m00")

    In CASA, simutil is a Python helper class in the private simutil module of CASA's task package, not a CASA tool, so it is not in casars.tools or in the object-surface bundle. casa-rs implements, in Rust (the class lives in the casars._core extension, ADR-0018), the parts sm scripts and simobserve use: - readantenna; - the pointings calc_pointings2, read_pointings and write_pointings; - the direction helpers direction_splitter, average_direction, median_direction, dir_m2s, wrapang, isquantity and isdirection; - noisetemp, bandname and polsettings; - itrf2loc, baselineLengths and approxBeam; - the sky-model helpers modifymodel and flatimage.

    casars.simutil is the class's public import: CASA's private path would mislabel a supported entry point.
