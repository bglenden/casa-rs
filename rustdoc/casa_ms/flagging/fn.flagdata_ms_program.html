Expand description

Execute a sequence of MeasurementSet flagging agents on one opened table view. Earlier agents’ staged edits are visible to later summary and propagation passes. CASA’s antenna-integration prepass reads the original input flags. When write_flags is false, staged flags are discarded without mutating the MeasurementSet on disk; when true, changed rows are written once at the end. When local_selection is true (multiple commands in CASA’s mode='list'), an agent whose local selection fails is skipped (None) rather than aborting the list; single-command runs propagate selection errors.
