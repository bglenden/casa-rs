2//! CASA's antenna (baseline) selection expressions, ported from casacore.
3//!
4//! [`resolve_antenna_selector`] parses the `antenna=` text of an
5//! `MSSelection` and resolves it against the ANTENNA table into a
6//! [`BaselineSelection`]: for every ordered (`ANTENNA1`, `ANTENNA2`) pair of
7//! a MAIN row, whether CASA would select that row. It follows casacore at
8//! commit `aaf72eb7` (the casacore of CASA 6.7.6.14): the scanner
9//! `ms/MSSel/MSAntennaGram.ll`, the grammar `MSAntennaGram.yy`, the
10//! selection logic `MSAntennaParse.cc` and the name lookups
11//! `MSAntennaIndex.cc`. Where these have quirks, CASA's behaviour is kept
12//! and the quirk is noted below.
13//!
14//! # Expressions
15//!
16//! An expression is one or more *terms* separated by `;`. A term is a
17//! baseline form applied to antenna lists, a baseline-regex list or a
18//! baseline-length list, optionally negated by a leading `!`.
19//!
20//! | Form | Selects (cross = `ANTENNA1 != ANTENNA2`) | C++ |
21//! |---|---|---|
22//! | `L` | cross baselines with an antenna of `L` on either side | `MSAntennaGram.yy:193-201`, `MSAntennaParse.cc:123-130,84-89` |
23//! | `L1&L2` | cross baselines with one side in `L1` and the other in `L2`, in either order | `.yy:168-178`, `.cc:157-176` |
24//! | `L&` | cross baselines between antennas of `L` | `.yy:179-192` |
25//! | `L1&&L2` | as `L1&L2`, also the autocorrelations of antennas in both lists | `.yy:202-212` |
26//! | `L&&` | as `L&` plus the autocorrelations of `L` | `.yy:213-221` |
27//! | `L&&&` | only the autocorrelations of `L` | `.yy:222-230`, `.cc:105-121` |
28//! | `/A&B/` (a regex holding `&`) | ordered pairs whose `NAME1&NAME2` the regex matches in full; autocorrelations too | `.ll:83-86`, `.cc:250-277` |
29//! | `<x`, `<=x`, `>x`, `>=x`, `a~b` with a length unit | baselines whose ITRF length lies in the interval, autocorrelations (length 0) too | `.yy:453-506`, `.cc:230-248,311-334` |
30//! | `!T` | the rows `T` does not select | `.yy:165`, `.cc:91` |
31//! | `T1;T2` | left to right: a plain term ORs with what precedes it, a `!` term ANDs | `.cc:92-95` |
32//!
33//! An antenna list `L` is a comma-separated list of:
34//!
35//! | Item | Antennas | C++ |
36//! |---|---|---|
37//! | name, e.g. `ea01` | rows whose NAME equals it; if none, rows whose STATION equals it | `.yy:293-306`, `MSAntennaIndex.cc:126-158` |
38//! | integer, e.g. `5` | the first row whose NAME (else STATION) is that text, else antenna ID 5 | `.yy:336-357` |
39//! | range `3~7` | each integer as above, its name written in plain decimal | `.yy:358-380` |
40//! | pattern, quoted (`"ea0*"`, `'ea{01,02}'`) or bare (`ea0*`, `ea0[1-3]`) | rows whose NAME, else STATION, matches in full; a leading `^` negates | `.ll:46-63,111-116`, `MSAntennaIndex.cc:82-122`, `Regex::fromPattern` |
41//! | regex `/ea0[1-3]/`, negated `^/.../` | as a pattern, the text an ECMAScript regex | `.ll:49,77-87` |
42//! | `\text` | the name `text`, which may then hold any non-blank characters | `.ll:59,104-109` |
43//! | `A@S`, `(A1,A2)@S`, `A@(S1,S2)`, `@S` | antennas of `A` standing at a station of `S` (exact STATION, pattern or regex) | `.yy:249-289,416-438` |
44//!
45//! Every name, pattern, station or ID that matches nothing is an error,
46//! raised once the whole expression has been read (`reportError`,
47//! `MSSelection.cc:858-864`), as are scanner and syntax errors, units that
48//! are not lengths and regexes that do not compile. The empty string is no
49//! constraint (`MSSelection.cc:590`); text of only blanks is a syntax error.
50//!
51//! # CASA quirks this port keeps
52//!
53//! - A purely numeric item is a NAME first: with an antenna named `"3"`,
54//!   `3` selects that antenna, not ID 3; only its first such row is kept
55//!   (`.yy:352-355`). A range looks up `std::ostringstream` decimal names,
56//!   so `01~02` looks up `"1"` and `"2"` while a lone `01` looks up `"01"`.
57//! - Integers are read with `atoi`: `4294967296` is antenna 0 (glibc keeps
58//!   the low 32 bits). A range `a~b` whose length `b - a + 1` is below zero
59//!   or overflows `Int` (`0~2147483647`) is an error, as the C++ `Vector`
60//!   allocation fails; a range reaching past the last antenna selects the
61//!   antennas that exist without complaint.
62//! - `!T` also selects every autocorrelation `T` excludes: `!ea01` selects
63//!   ea01's own autocorrelation, since `T` masks autocorrelations before
64//!   the negation (`.cc:84-91`).
65//! - `;` is not commutative: `ea01;!ea02` is (ea01 baselines) AND NOT
66//!   (ea02 baselines), but `!ea02;ea01` is (NOT ea02 baselines) OR (ea01
67//!   baselines).
68//! - A leading `^` inside a regex or pattern is negation, not an anchor:
69//!   `/^ea0[12]/` selects every antenna but ea01 and ea02.
70//! - Patterns and regexes fall back to STATION per antenna; exact names fall
71//!   back to STATION only when no NAME matches at all.
72//! - A baseline regex is matched against the ordered string
73//!   `NAME(ANTENNA1)&NAME(ANTENNA2)`, so `/ea01&ea02/` selects the rows with
74//!   ANTENNA1 = ea01 and ANTENNA2 = ea02 but not the reverse; one that
75//!   matches nothing selects nothing silently (`.cc:299-308`).
76//! - Length forms: `<x` and `>x` move the bound by 1e-9 m; a range of plain
77//!   integers with a unit (`100~200m`) is an antenna-ID range followed by a
78//!   stray unit, hence a syntax error: write `100m~200m` or `100.~200.m`.
79//! - Concatenated quotes keep their inner quotes (`"ea"'01'` is the
80//!   pattern `ea"'01`, `.ll:69-75`).
81//!
82//! # Not ported
83//!
84//! - ECMAScript backreferences, lookahead and `\u` escapes in regexes are
85//!   refused: the `regex` crate has none of them.
86//! - ANTENNA `POSITION` is read as ITRF, as everywhere in casa-ms; CASA
87//!   converts other reference frames with `MPosition::Convert`.
88//! - Messages follow CASA's wording but not its character positions
89//!   exactly.

106/// One ANTENNA table row as antenna selection reads it. In a slice of these,
107/// row `i` is antenna ID `i`.
108///
109/// Cf. the NAME, STATION and POSITION columns `MSAntennaIndex` and
110/// `MSAntennaParse::getBaselineLengths` read. `FLAG_ROW` plays no part:
111/// casacore's checks of it are commented out (`MSAntennaIndex.cc:117`).
112#[derive(Clone, Copy, Debug, PartialEq)]
113pub struct AntennaRow<'a> {
114    /// The NAME column, compared exactly (no trimming, case-sensitive).
115    pub name: &'a str,
116    /// The STATION column, compared exactly.
117    pub station: &'a str,
118    /// The stored POSITION components, ordinarily geocentric ITRF metres.
119    /// CASA's baseline-length selectors use the table's values directly.
120    pub position_m: [f64; 3],
121}

127    station: String,

129}

143/// A resolved antenna selection: which ordered (`ANTENNA1`, `ANTENNA2`)
144/// pairs of MAIN rows CASA's `MSSelection` would keep.
145///
146/// It holds a dense `(n + 2) × (n + 2)` table of booleans for `n` antennas.
147/// The two extra entries on each side stand for antenna IDs that are not
148/// ANTENNA rows: CASA's TaQL compares such an ID with no listed antenna, so
149/// the answer for one depends only on whether it equals the other side.
150/// An empty expression holds no table and selects everything.
151#[derive(Clone, Debug, PartialEq, Eq)]
152pub struct BaselineSelection {
153    antenna_count: usize,
154    /// Row-major over `0..antenna_count + 2`; `None` when unconstrained.
155    pairs: Option<Box<[bool]>>,
156}
157
158impl BaselineSelection {
159    fn unconstrained(antenna_count: usize) -> Self {
160        Self {
161            antenna_count,
162            pairs: None,
163        }
164    }
165
166    /// The number of ANTENNA rows the expression was resolved against.
167    pub fn antenna_count(&self) -> usize {
168        self.antenna_count
169    }
170
171    /// Whether the expression was empty, so every row is selected.
172    pub fn is_unconstrained(&self) -> bool {
173        self.pairs.is_none()
174    }
175
176    /// Whether a MAIN row with these `ANTENNA1` and `ANTENNA2` values is
177    /// selected. The order matters only for baseline-regex terms.
178    ///
179    /// IDs at or past [`antenna_count`](Self::antenna_count) are answered as
180    /// CASA's row predicate answers them: they match no name, station,
181    /// pattern or ID, so for example `!ea01` selects them and `ea01` does
182    /// not.
183    pub fn holds(&self, antenna1: usize, antenna2: usize) -> bool {
184        let Some(pairs) = &self.pairs else {
185            return true;
186        };
187        let count = self.antenna_count;
188        let row = antenna1.min(count);
189        let column = if antenna2 < count {
190            antenna2
191        } else if antenna2 == antenna1 {
192            count
193        } else {
194            count + 1
195        };
196        pairs[row * (count + 2) + column]
197    }
198
199    /// The heap bytes this selection owns: its pair table, one byte per
200    /// entry, `(n + 2)²` for `n` antennas, or nothing when unconstrained.
201    pub fn allocated_bytes(&self) -> usize {
202        self.pairs.as_ref().map_or(0, |pairs| size_of_val(&**pairs))
203    }
204}

206/// Resolve CASA antenna selection `text` against `antennas`, the ANTENNA
207/// table's rows in row order.
208///
209/// The empty string is no constraint, as `MSSelection` skips an empty
210/// antenna expression. See the [module documentation](self) for the
211/// expression forms and how each selects baselines.
212///
213/// # Errors
214///
215/// [`MsError::InvalidInput`], worded as CASA's
216/// `MSSelectionAntennaParseError`, when the text does not scan or parse,
217/// when any name, pattern, regex, station or ID in it matches no antenna,
218/// when a length unit is unknown or not a distance, or when a regex does
219/// not compile or uses an ECMAScript feature the port lacks.
220pub fn resolve_antenna_selector(
221    antennas: &[AntennaRow<'_>],
222    text: &str,
223) -> MsResult<BaselineSelection> {
224    resolve_antenna_expression(antennas, text, true)
225}

227/// Resolve the two antenna lists of an MSSelection expression. A consumer
228/// that selects calibration rows by antenna membership can use these lists
229/// independently of the visibility-baseline predicate.
230///
231/// # Errors
232/// The same antenna expression and lookup errors as [`resolve_antenna_selector`].
233pub fn resolve_antenna_lists(
234    antennas: &[AntennaRow<'_>],
235    text: &str,
236) -> MsResult<(Vec<i32>, Vec<i32>)> {
237    use std::collections::BTreeSet;
238
239    let mut first = BTreeSet::new();
240    let mut second = BTreeSet::new();
241    for clause in antenna_clauses(antennas, text, true)? {
242        let signed = |id: usize| {
243            if clause.negate {
244                -(id as i32)
245            } else {
246                id as i32
247            }
248        };
249        match clause.term {
250            Term::Cross(ids) | Term::AutoOnly(ids) => {
251                first.extend(ids.into_iter().map(signed));
252                second.extend((0..antennas.len()).map(signed));
253            }
254            Term::Pair {
255                first: left,
256                second: right,
257                ..
258            } => {
259                first.extend(left.into_iter().map(signed));
260                second.extend(right.into_iter().map(signed));
261            }
262            // Ordered predicates from baseline patterns and lengths do not
263            // publish named antenna indices in CASA's selection lists.
264            Term::Ordered(_) => (),
265        }
266    }
267    Ok((first.into_iter().collect(), second.into_iter().collect()))
268}

277impl MeasurementSet {
278    pub(super) fn antenna_selection_indices(
279        &self,
280        text: &str,
281    ) -> MsResult<AntennaSelectionIndices> {
282        use std::collections::HashSet;
283
284        self.with_antenna_rows(|rows| {
285            let mut result = AntennaSelectionIndices::default();
286            let mut seen_pairs = HashSet::new();
287            let mut first_ids = HashSet::new();
288            let mut second_ids = HashSet::new();
289            let count = rows.len();
290            let mut add = |first: i32, second: i32| {
291                let pair = (first.min(second), first.max(second));
292                if seen_pairs.insert(pair) {
293                    result.baselines.push([first, second]);
294                }
295            };
296            for clause in antenna_clauses(rows, text, true)? {
297                let signed = |id: usize| {
298                    let value = id as i32;
299                    if clause.negate { -value } else { value }
300                };
301                let (first, second, baseline_type) = match &clause.term {
302                    Term::Cross(ids) => (
303                        ids.iter().copied().map(signed).collect::<Vec<_>>(),
304                        (0..count as i32).collect::<Vec<_>>(),
305                        BaselineType::Cross,
306                    ),
307                    Term::AutoOnly(ids) => (
308                        ids.iter().copied().map(signed).collect(),
309                        (0..count as i32).collect(),
310                        BaselineType::Auto,
311                    ),
312                    Term::Pair {
313                        first,
314                        second,
315                        autocorrelations,
316                    } => (
317                        first.iter().copied().map(signed).collect(),
318                        second.iter().copied().map(signed).collect(),
319                        if *autocorrelations {
320                            BaselineType::Both
321                        } else {
322                            BaselineType::Cross
323                        },
324                    ),
325                    Term::Ordered(pairs) => {
326                        for (slot, &present) in pairs.iter().enumerate() {
327                            if present {
328                                add((slot / count) as i32, (slot % count) as i32);
329                            }
330                        }
331                        continue;
332                    }
333                };
334                result
335                    .first
336                    .extend(first.iter().copied().filter(|&id| first_ids.insert(id)));
337                result
338                    .second
339                    .extend(second.iter().copied().filter(|&id| second_ids.insert(id)));
340                for &left in &first {
341                    for &right in &second {
342                        let keep = match baseline_type {
343                            BaselineType::Cross => left != right,
344                            BaselineType::Auto => left == right,
345                            BaselineType::Both => true,
346                        };
347                        if keep {
348                            add(left, right);
349                        }
350                    }
351                }
352            }
353            Ok(result)
354        })
355    }
356}

365fn resolve_antenna_expression(
366    antennas: &[AntennaRow<'_>],
367    text: &str,
368    reject_unmatched: bool,
369) -> MsResult<BaselineSelection> {
370    if text.is_empty() {
371        return Ok(BaselineSelection::unconstrained(antennas.len()));
372    }
373    let clauses = antenna_clauses(antennas, text, reject_unmatched)?;
374    Ok(BaselineSelection {
375        antenna_count: antennas.len(),
376        pairs: Some(evaluate(&clauses, antennas.len(), false)),
377    })
378}
379
380fn antenna_clauses(
381    antennas: &[AntennaRow<'_>],
382    text: &str,
383    reject_unmatched: bool,
384) -> MsResult<Vec<Clause>> {
385    let index = AntennaIndex::new(antennas);
386    let parsed = grammar::parse(&index, text)
387        .map_err(|(abort, reports)| failure(text, &reports, Some(abort)))?;
388    if !parsed.reports.is_empty() {
389        let report = failure(text, &parsed.reports, None);
390        if reject_unmatched {
391            return Err(report);
392        }
393        tracing::warn!("{report}");
394    }
395    Ok(parsed.clauses)
396}

399    /// CASA's antenna-1 list includes negative IDs from negated clauses.
400    pub fn signed_antenna1_indices(&self, text: &str) -> MsResult<Vec<i32>> {
401        self.with_antenna_rows(|rows| {
402            let mut seen = std::collections::BTreeSet::new();
403            let mut indices = Vec::new();
404            for clause in antenna_clauses(rows, text, true)? {
405                let ids = match clause.term {
406                    Term::Cross(ids) | Term::AutoOnly(ids) | Term::Pair { first: ids, .. } => ids,
407                    Term::Ordered(_) => continue,
408                };
409                for id in ids {
410                    let id = if clause.negate {
411                        -(id as i32)
412                    } else {
413                        id as i32
414                    };
415                    if seen.insert(id) {
416                        indices.push(id);
417                    }
418                }
419            }
420            Ok(indices)
421        })
422    }

424    /// Antennas listed by `MSSelection` for reindexing a transformed MS.
425    pub fn transform_antenna_ids(&self, text: &str) -> MsResult<Vec<i32>> {
426        self.with_antenna_rows(|rows| {
427            let mut ids = std::collections::BTreeSet::new();
428            for clause in antenna_clauses(rows, text, true)? {
429                match clause.term {
430                    // Single-list terms put the whole ANTENNA table in the
431                    // second list (MSAntennaParse::selectAntennaIds).
432                    Term::Cross(_) | Term::AutoOnly(_) => {
433                        return Ok((0..rows.len() as i32).collect());
434                    }
435                    Term::Pair { first, second, .. } => ids.extend(
436                        first
437                            .into_iter()
438                            .chain(second)
439                            .filter(|&id| !clause.negate || id == 0)
440                            .map(|id| id as i32),
441                    ),
442                    Term::Ordered(_) => (),
443                }
444            }
445            Ok(ids.into_iter().collect())
446        })
447    }

545/// Resolve the ordered, nonnegative first-antenna indices of a CASA
546/// reference expression against antenna metadata. An empty expression
547/// selects no reference. This takes the same priority order as
548/// [`MeasurementSet::resolve_reference_antennas`].
549///
550/// # Errors
551/// When the antenna expression is invalid or a token matches no antenna.
552pub fn resolve_reference_antennas(antennas: &[AntennaRow<'_>], text: &str) -> MsResult<Vec<usize>> {
553    resolve_antenna1_indices(antennas, text, false)
554}
555
556fn resolve_antenna1_indices(
557    rows: &[AntennaRow<'_>],
558    text: &str,
559    reject_negative: bool,
560) -> MsResult<Vec<usize>> {
561    if text.is_empty() {
562        return Ok(Vec::new());
563    }
564    let mut seen = vec![false; rows.len()];
565    let mut antennas = Vec::new();
566    for clause in antenna_clauses(rows, text, true)? {
567        let ids = match clause.term {
568            Term::Cross(ids) | Term::AutoOnly(ids) | Term::Pair { first: ids, .. } => ids,
569            Term::Ordered(_) => continue,
570        };
571        for id in ids {
572            if clause.negate && id != 0 {
573                if reject_negative {
574                    return Err(MsError::InvalidInput(format!(
575                        "antenna selector {text:?} produces a negative calibration index for antenna {id}"
576                    )));
577                }
578                continue;
579            }
580            if !seen[id] {
581                seen[id] = true;
582                antennas.push(id);
583            }
584        }
585    }
586    Ok(antennas)
587}

589/// One term and whether `!` negates it.
590struct Clause {
591    term: Term,
592    negate: bool,
593}
594
595/// The row condition of one term, over existing antenna IDs.
596enum Term {
597    /// `selectAntennaIds(ids, CrossOnly)`: either side in the list.
598    Cross(Vec<usize>),
599    /// `selectAntennaIds(first, second, type)`: one side in each list.
600    Pair {
601        first: Vec<usize>,
602        second: Vec<usize>,
603        autocorrelations: bool,
604    },
605    /// `selectAntennaIds(ids, AutoCorrOnly)`.
606    AutoOnly(Vec<usize>),
607    /// `makeBLNode`: an `n × n` row-major table of selected ordered pairs.
608    Ordered(Vec<bool>),
609}
610
611/// Evaluate the terms over every (`ANTENNA1`, `ANTENNA2`) slot, as
612/// `MSAntennaParse::setTEN` (`MSAntennaParse.cc:80-98`) combines them.
613fn evaluate(clauses: &[Clause], count: usize, solution_antenna: bool) -> Box<[bool]> {
614    let side = count + 2;
615    let mut selected = vec![false; side * side].into_boxed_slice();
616    for (position, clause) in clauses.iter().enumerate() {
617        let condition = condition(&clause.term, count, solution_antenna);
618        for antenna1 in 0..side {
619            for antenna2 in 0..side {
620                let value = condition(antenna1, antenna2) != clause.negate;
621                let cell = &mut selected[antenna1 * side + antenna2];
622                *cell = if position == 0 {
623                    value
624                } else if clause.negate {
625                    *cell && value
626                } else {
627                    *cell || value
628                };
629            }
630        }
631    }
632    selected
633}
634
635/// The row condition of `term` over slots `0..count + 2`; slots from
636/// `count` on are IDs no list contains.
637fn condition(
638    term: &Term,
639    count: usize,
640    solution_antenna: bool,
641) -> Box<dyn Fn(usize, usize) -> bool + '_> {
642    let side = count + 2;
643    let mask = move |ids: &[usize]| {
644        let mut members = vec![false; side];
645        for &id in ids {
646            members[id] = true;
647        }
648        members
649    };
650    match term {
651        Term::Cross(ids) => {
652            let members = mask(ids);
653            Box::new(move |a1, a2| {
654                if solution_antenna {
655                    members[a1]
656                } else {
657                    a1 != a2 && (members[a1] || members[a2])
658                }
659            })
660        }
661        Term::Pair {
662            first,
663            second,
664            autocorrelations,
665        } => {
666            let (first, second) = (mask(first), mask(second));
667            let autocorrelations = *autocorrelations;
668            Box::new(move |a1, a2| {
669                if solution_antenna {
670                    first[a1]
671                } else {
672                    (autocorrelations || a1 != a2)
673                        && ((first[a1] && second[a2]) || (second[a1] && first[a2]))
674                }
675            })
676        }
677        Term::AutoOnly(ids) => {
678            let members = mask(ids);
679            Box::new(move |a1, a2| a1 == a2 && members[a1])
680        }
681        Term::Ordered(table) => {
682            Box::new(move |a1, a2| a1 < count && a2 < count && table[a1 * count + a2])
683        }
684    }
685}

687/// The `MsError` for a refused expression. "No match" reports win over the
688/// error that stopped the parse, as `MSSelection::toTableExprNode` runs
689/// the error handler before rethrowing (`MSSelection.cc:759-765`); their
690/// text is `MSSelectionErrorHandler::constructMessage`
691/// (`MSSelectionErrorHandler.cc:63-77`).
692fn failure(text: &str, reports: &[Report], abort: Option<Abort>) -> MsError {
693    let message = match (reports.first(), abort) {
694        (Some(first), _) => {
695            let mut message = first.message.clone();
696            for report in reports {
697                message.push_str(&report.token);
698                message.push(' ');
699            }
700            message.trim_end().to_string()
701        }
702        (None, Some(Abort(message))) => message,
703        (None, None) => String::from("Antenna Expression: no selection"),
704    };
705    MsError::InvalidInput(format!("antenna selection {text:?}: {message}"))
706}
