# Branding Assets

Generated visual identity assets for casa-rs: the documentation header
(`headers/casa-rs-header.png`, shown at the top of the repository README), the
app icon (`app-icon/`, as `.icns` and PNG exports from 16 to 1024 px), and the
original generated source images (`source/`) for future revisions.

The design is a radio-observatory assistant with side dish panels, a copper
Rust-inspired gear halo, cyan interferometry arcs, and dark observatory-night
radio-array imagery: a nod to CASA's radio astronomy heritage that stays
visually distinct from official CASA branding.
