Crate casa_imaging_runtime 

Source
Expand description

Imaging execution (plan section 5.4): host resources and per-phase admission, the major-cycle pass on the bounded worker team, cooperative cancellation, the paged cube state, the minor-cycle adapter and the run summary.

Modules§

pass
The major-cycle pass (plan section 5.4): one traversal of the selected visibilities that accumulates the dirty or residual image terms, and the PSF on the initial pass, of every image domain, for every capability.
