Crate casa_imaging_products 

Source
Expand description

Native continuum product algorithms and bounded write-only generation.

This owner turns one authoritative Major-Cycle result into complete, generation-consistent continuum products: restoring-beam fitting, restoration, residual scaling, normalization, validity, metadata, and the exact member set declared by the compiler-owned Product Graph. It owns the generation-construction capability and transfers bounded windows directly to a caller-owned write-only output.
