Expand description

Keep auxiliary files and access modes from a locked source tree when publishing a newly written replacement. Generated casacore files retain their contents. An obsolete source storage file is never reinstated.

§Errors

Returns an error if either tree cannot be inspected or the private replacement cannot preserve its source’s files and modes.
