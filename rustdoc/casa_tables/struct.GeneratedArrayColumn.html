Struct GeneratedArrayColumn

pub struct GeneratedArrayColumn { /* private fields */ }
Expand description

Generated array-column override for high-volume table writers.

The cells are given by row number, either by a closure evaluated for each row (new) or as runs of one value (from_array_runs, constant), so a writer such as a simulator’s POINTING subtable never materializes a [Value] per cell. Insert it with ColumnOverrides::insert_generated_array.

Only StandardStMan and IncrementalStMan write generated array columns, and every column of the data-manager group must then be overridden. IncrementalStMan stores Direct fixed-shape arrays only: casacore keeps other arrays in an ISMIndColumn’s table.fNi file, which casa-rs does not write. Run values are checked against the column’s schema when the save starts; a per-row closure’s cells are checked against the column’s type and shape as they are written.

pub fn from_array_runs( row_count: usize, runs: Vec<GeneratedArrayValueRun>, ) -> Result<Self, TableError>

A column of row_count cells given as runs.

The first run must start at row 0, the runs must start at strictly increasing rows below row_count, and each holds until the next starts or the column ends. For zero rows, runs must be empty.

§Errors

TableError::InvalidGeneratedArrayRuns when the run starts break those rules.
