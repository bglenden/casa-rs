Module ascii 

Source
Expand description

Read the casacore ASCII table format and write the CASA table tool’s text dump.

The input accepts native flat arrays (for example D2,3). The output uses brackets (D[2,3]), as CASA’s toasciifmt does. They are distinct formats.
