Expand description

Additional options used by the CASA task surfaces.

Fields§

§visibility_columns: Option<Vec<OptionalMainColumn>>

Explicit visibility columns for callers that accept arbitrary combinations. Ordinary task surfaces select a predefined combination on the request.

§legacy_tool: Option<LegacyMsTool>

Match the legacy Python MeasurementSet tool’s output conventions.

§legacy_continuum_output: Option<String>

The contsub fit’s output spectral windows. The request’s union still determines subtable IDs, and its correlation selector filters rows.

§use_weight_spectrum: bool

Create and fill weight and sigma spectra even when the input has none.

§tiling: Option<MsTransformTiling>

CASA task preference for the output’s array storage.

§preserve_ids: bool

Keep original field, antenna, observation, state and spectral IDs.

§ddi_start: usize

First output data-description ID when spectral IDs are reassigned.

§hanning: bool

Apply a three-channel Hanning window after selection and averaging.

§combine_spws: bool

Combine selected spectral windows for each simultaneous baseline sample.

§continuum: Option<ContinuumFitOptions>

Fit and subtract a continuum, or produce just the fitted continuum.

§regrid: Option<MsRegridOptions>

Transform the selected spectra onto a new frequency grid.

§channel_widths: Option<Vec<usize>>

Active per-selected-SPW widths, or a single width broadcast to each SPW. When absent, the task uses the scalar width in the request. In legacy split mode, zero represents an invalid negative Python step.

§time_averaging: Option<TimeAverageOptions>

Average visibilities along each baseline within this time bin.

§single_dish_polarization: Option<SingleDishPolarizationAverage>

Combine selected single-dish parallel hands when time averaging is absent.

§history: Option<TransformTaskHistory>

Provenance rows to append to the output’s HISTORY table.

§flag_command_widths: Option<Vec<i64>>

Supplied bin widths used when rewriting saved FLAG_CMD selectors. CASA interprets them independently of visibility averaging.

§keep_mms: Option<bool>

The split task’s decision to retain or flatten a Multi-MS input.

§retained_scan_span: Option<f64>

The raw numeric timebin for retained split’s exact combine=“scan” check.

§multi_ms: Option<MsTransformMultiMsOptions>

Multi-MS dispatch for the public mstransform task.

§input_view: Option<Arc<dyn TransformInputView>>

Computed arrays to read in place of stored input values.
