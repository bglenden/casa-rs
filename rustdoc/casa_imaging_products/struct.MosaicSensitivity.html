Struct MosaicSensitivity

pub struct MosaicSensitivity<'a> { /* private fields */ }
Expand description

One plane’s direction-dependent sensitivity, borrowed from the normal state.

It derives CASA’s unit-peak PB, the flat-noise and flat-sky residuals, PB support and the apparent and physical model. It owns no CLEAN mask and leaves the normal state unchanged.

pub fn normalize( self, values: &[f32], normalization: ProductNormalization, policy: PrimaryBeamValidityPolicy, ) -> Result<Vec<f32>, ProductsError>

Normalize a raw residual plane to flat noise or flat sky.

This is Self::normalize_weighted_residual_sample in the raw sensitivity’s units, where every sum of weights cancels: flat noise divides by √(|sensitivity|·peak) where that exceeds cutoff·peak, flat sky by the sensitivity where it exceeds cutoff²·peak, and the residual is zero elsewhere.

§Errors

Unit-response normalization, or a non-finite result.

§Panics

If values is not one value per sensitivity pixel.

Source

pub fn normalize_weighted_residual_sample( self, value: f64, index: usize, normalization: ProductNormalization, family: ResidualFamily, published_sum_weight: f64, policy: PrimaryBeamValidityPolicy, ) -> Result<f64, ProductsError>

Normalize a residual through CASA’s Float sum-weight and weight-image stages.

The normal sum weight is bound by Self::with_normal_sum_weight. All Taylor terms divide by the principal publication sum weight given here. Flat noise divides by sqrt(abs(weight)) * PBScale where that exceeds cutoff * PBScale^2: PB > cutoff. Flat sky divides by weight where it exceeds cutoff^2 * PBScale^2 for one term (PB > cutoff) and cutoff * PBScale^2 for a Taylor family (PB > √cutoff), as CASA’s two image stores do. Elsewhere the residual is zero.

§Errors

Unit-response normalization, or non-finite input or arithmetic.

Form CASA’s cutoff-blanked Float PB from the bound normalized weight.
