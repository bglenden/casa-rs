Expand description

Decode a FITS header and report each model axis’s original FITS pixel axis.

The model groups direction axes together, even when their position differs in the input array. Use the resulting permutation when saving a record for an array that retains the original FITS axis order.

§Errors

Returns a coordinate error when the header cannot produce a model.
