Expand description

Shape of an accumulator: which planes, polarizations, terms and window it holds, over which geometry.

Cells are laid out [plane][pol][term][y][x], x fastest, with the terms of each held mode concatenated in the order data, PSF, weight. The same layout is the device buffer, so a device copy is one memcpy.

pub fn new( geometry: GridGeometry, planes: PlaneRange, pols: usize, modes: ModeSet, data_terms: usize, psf_terms: usize, tile: Option<Tile>, ) -> Self

Layout holding modes over planes × pols grid polarizations.

data_terms is the number of Taylor terms (1 for other bases) and psf_terms is 2·data_terms − 1; the weight image has one term.
