imstat’s statistics record over the whole selection, as CASA returns it with axes=[]: each statistic a one-element float64 array, and the corners and extremum positions int64 pixel arrays. A selection with no valid pixel has each statistic, flux among them, as an empty float64 array and no extremum positions, as CASA 6.7.6.14 returns it.
