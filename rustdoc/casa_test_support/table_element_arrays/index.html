Module table_element_arrays 

Source
Expand description

The every-type array fixtures of the table cross matrix.

Arrays of every element type in ELEMENT_ROWS rows, as casacore_cpp_table_element_arrays.cpp makes them, in families of columns by how they are stored (ElementStorage): fixed-shape arrays of shapes [1], [3] and [2, 3], named <type>_<shape> (Float64_2x3) when stored directly and <type>_<shape>_ind when stored in the storage manager’s array file, and variable-shape arrays of rank 1, named <type>_var, whose cell in row row has row + 1 elements (and <type>_undef, the same with row 0 undefined). Element index, in storage (Fortran) order, of row row is made from 7 + 10 row + index, so Float64_1 holds [7.0] in row 0.
