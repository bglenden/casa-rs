Expand description

Fit a restoring beam from one real PSF plane stored x-major.

The plane is indexed [x * height + y] like every normal-state primitive. cutoff is the CASA psfcutoff fraction of the peak that bounds the main lobe; failed fits retry at progressively lower cutoffs exactly like the reference workflow. Pixel sizes are radians per pixel on each axis.

§Errors

Returns PsfBeamFitError when no attempt converges.
