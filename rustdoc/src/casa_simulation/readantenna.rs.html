2//! Antenna configuration files: CASA's `simutil.readantenna`.
3//!
4//! `simobserve` and `simalma` read the array from a text file such as
5//! CASA's `alma.cycle10.3.cfg`:
6//!
7//! ```text
8//! # observatory=ALMA
9//! # coordsys=LOC (local tangent plane)
10//! # x             y               z             diam  station  ant
11//! -5.850273514   -125.9985379    -1.590364043   12.   A058     DA41
12//! -19.90369337    52.82680653    -1.892119601   12.   A023     DA42
13//! ```
14//!
15//! [`read_antenna_config`] reads one and returns what CASA's
16//! `readantenna` returns: Earth-centred (ITRF) antenna positions, dish
17//! diameters, pad and antenna names, the telescope name and the observatory
18//! position.
19//!
20//! # The format
21//!
22//! - **Header lines** start with `#`. When the text after the `#` holds
23//!   exactly one `=`, the two sides, stripped of every `#` and of
24//!   surrounding white space, are a `key=value` parameter; the key is all
25//!   the text before the `=`. Other header lines are comments. Headers may
26//!   appear anywhere, and a later duplicate wins.
27//! - **Antenna lines** lose everything from their first `#`. Their
28//!   white-space-separated columns are x, y, z, diameter (metres, parsed as
29//!   Python's `float`), the pad (station) name and the antenna name. With
30//!   five columns the pad is also the antenna name; with four, both are
31//!   `A%02d` for the antenna's index.
32//! - **`coordsys`** (required) says what x, y, z are. Its value is
33//!   upper-cased; `XYZ` and `UTM` must match exactly and `LOC` matches its
34//!   first three characters (CASA's own files say
35//!   `coordsys=LOC (local tangent plane)`).
36//!   - `XYZ`: ITRF x, y, z, used as they are.
37//!   - `UTM`: easting, northing and elevation, with the required headers
38//!     `zone`, `datum` (a code of [`geodesy::DATUMS`], case-sensitive) and
39//!     `hemisphere` (south when its first letter is `S` or `s`), converted
40//!     with [`geodesy::utm_to_xyz`].
41//!   - `LOC`: east, north and up offsets from the observatory, converted
42//!     with [`geodesy::local_to_itrf`] at the observatory's geodetic WGS 84
43//!     latitude, longitude and height.
44//! - **`observatory`** names the telescope (`SIMULATED` without one).
45//! - **`COFA=lon,lat`** (degrees) sets the observatory position, at height
46//!   zero; it overrides a known observatory, with a warning.
47//!
48//! # The observatory position
49//!
50//! In CASA's order:
51//! 1. `COFA`, when given.
52//! 2. A known observatory: the measures provider's observatory table
53//!    (CASA's `me.observatory`), converted to WGS 84. The name matches as
54//!    casacore's `MeasTable::Observatory` matches it: a case-insensitive
55//!    exact match, else the one table name that is a prefix of the
56//!    telescope name (CASA's `aca.tp.cfg` says `observatory=ALMASD`, which
57//!    is ALMA). Two such names (`GB` and `GBT` for `GBTX`) match none.
58//! 3. Otherwise a `LOC` file is an error, and for absolute coordinates the
59//!    observatory is the mean antenna position, converted to WGS 84 with
60//!    [`geodesy::xyz_to_geodetic`].
61//!
62//! The position is returned in WGS 84, as CASA returns it.
63//!
64//! # Where this differs from CASA
65//!
66//! CASA's `readantenna` has bugs on some paths. These follow its evident
67//! intent instead. Each was confirmed by running CASA 6.7.6 unless it says
68//! otherwise.
69//! - **Blank and short lines.** Lines that are neither headers nor
70//!   antennas (blank lines, lines with fewer than four columns) are
71//!   skipped. CASA means to skip them (`pass  # ignore empty rows`) but
72//!   appends a default `A%02d` pad and antenna name for each, numbered by
73//!   line. Its name lists then outgrow the positions and pair with the
74//!   wrong antennas: for CASA's `WSRT.cfg`, whose header has two blank
75//!   lines, it returns 16 names for 14 antennas, starting `A00`, `A01`,
76//!   `RT0`.
77//! - **The mean position.** For an unknown observatory without `COFA`, CASA
78//!   averages the loop variable `x` left over from the coordinate
79//!   conversion. For `XYZ` files that variable does not exist and CASA
80//!   raises `UnboundLocalError`; for `UTM` files it is the last antenna's
81//!   x, y, z. CASA also unpacks `xyz2long`'s longitude, latitude, height as
82//!   latitude, longitude, height, so its position has the two angles
83//!   swapped. Here the observatory is `xyz2long` of the mean of the ITRF
84//!   antenna positions, as CASA's comment says.
85//! - **Errors.**
86//!   - A `coordsys` that is none of `XYZ`, `UTM`, `LOC…` is an error. CASA
87//!     returns no positions (and, through the blank-line bug, one name per
88//!     antenna line).
89//!   - A non-integer `zone`, an empty `hemisphere` and a malformed `COFA`
90//!     are errors with messages in CASA's style, where CASA lets Python's
91//!     `ValueError` or `IndexError` escape.
92//!   - A number that does not parse is CASA's `Could not read file` error,
93//!     with the line and the text added.
94//!   - `zone` and `datum` are checked even when there are no antennas,
95//!     where CASA never converts them (from CASA's source).
96//! - **Unresolvable names.** CASA counts a telescope as known when any
97//!   table name is a substring of it, then looks it up with
98//!   `me.observatory`, which can fail (`xALMAx`). CASA then raises
99//!   `KeyError` for a `LOC` file and takes the mean-position path otherwise;
100//!   here such a name is simply unknown.
101//! - **Prefix ambiguity.** casacore also counts a longer table name that
102//!   starts with the telescope name as a candidate (`MWA3` matches both
103//!   `MWA` and `MWA32T`, so neither; from casacore's `MUString::minimaxNC`).
104//!   The measures provider only answers exact lookups and cannot list its
105//!   table, so that case resolves to the shorter name here.
106//! - **`COFA` height.** The observatory is at height 0. casacore stores a
107//!   zero-height WGS 84 position as a 1e-6 m vector, so CASA's position, and
108//!   the height its `LOC` conversion uses, is 1e-6 m.
109//! - **Conversion to WGS 84** of an observatory tabulated in ITRF uses
110//!   [`MPosition::convert_to`] (SOFA's `gc2gd`) rather than casacore's
111//!   iteration. For real sites they agree to about 1e-14 rad and 1e-9 m.
112//!   CASA's table also has placeholder entries at or near the geocentre
113//!   (`VLBA` and `EVN` at ITRF (1e-6, 0, 0) m; `LOFAR`, `OVRO_MMA` and
114//!   `SUNRISE` within a kilometre of it), whose geodetic positions are
115//!   meaningless either way: for CASA's `vlba.cfg` CASA's observatory is
116//!   (0, 0, 742.93 m) and this one (0, 0, −6378137 m). `XYZ` antenna
117//!   positions do not depend on it.
118//! - **Numbers** with non-ASCII decimal digits, which Python's `float`
119//!   accepts, are rejected (from Python's documentation).

133/// How a configuration file gives its antenna positions (`coordsys`).
134#[derive(Debug, Clone, Copy, PartialEq, Eq)]
135pub enum ConfigCoordinates {
136    /// `XYZ`: Earth-centred ITRF x, y, z.
137    Xyz,
138    /// `UTM`: easting, northing and elevation in one UTM zone.
139    Utm,
140    /// `LOC…`: east, north, up offsets from the observatory.
141    Local,
142}
143
144/// Where [`AntennaConfigFile::observatory`] comes from.
145#[derive(Debug, Clone, Copy, PartialEq, Eq)]
146pub enum ObservatorySource {
147    /// The measures provider's observatory table.
148    Catalog,
149    /// The `COFA` header.
150    Cofa,
151    /// The mean antenna position (an unknown observatory with absolute
152    /// coordinates).
153    MeanAntennaPosition,
154}

156/// An antenna configuration file as CASA's `readantenna` returns it.
157///
158/// The vectors run over antennas in file order and have equal lengths.
159/// CASA's return tuple is `(x, y, z, dish_diameter, pad_names,
160/// antenna_names, telescope, observatory)`.
161#[derive(Debug, Clone)]
162pub struct AntennaConfigFile {
163    /// ITRF x of each antenna, metres.
164    pub x: Vec<f64>,
165    /// ITRF y of each antenna, metres.
166    pub y: Vec<f64>,
167    /// ITRF z of each antenna, metres.
168    pub z: Vec<f64>,
169    /// Dish diameters, metres.
170    pub dish_diameter: Vec<f64>,
171    /// Pad (station) names: the fifth column.
172    pub pad_names: Vec<String>,
173    /// Antenna names: the sixth column, else the pad name.
174    pub antenna_names: Vec<String>,
175    /// The `observatory` header, or [`SIMULATED_TELESCOPE`].
176    pub telescope: String,
177    /// The observatory position in WGS 84 (CASA's `posobs`).
178    pub observatory: MPosition,
179    /// How [`Self::observatory`] was found.
180    pub observatory_source: ObservatorySource,
181    /// The file's coordinate system.
182    pub coordinates: ConfigCoordinates,
183    /// Every `key=value` header parameter, values as written.
184    pub header: BTreeMap<String, String>,
185}

187/// A configuration file that cannot be read. Where CASA reports the same
188/// failure, the message is CASA's.
189#[derive(Debug, Error)]
190pub enum ReadAntennaError {
191    /// The file could not be read.
192    #[error("Could not read file: '{}': {source}", path.display())]
193    Io {
194        /// The file.
195        path: PathBuf,
196        /// The I/O error.
197        source: std::io::Error,
198    },
199    /// An antenna column that should be a number is not one.
200    #[error("{}", invalid_number_message(.path.as_deref(), .line, .value))]
201    InvalidNumber {
202        /// The file, when the configuration was read from one.
203        path: Option<PathBuf>,
204        /// The 1-based line number.
205        line: usize,
206        /// The column's text.
207        value: String,
208    },
209    /// The header has no `coordsys`.
210    #[error("Must specify XYZ, UTM or LOC coordinate system in antenna file header")]
211    MissingCoordinateSystem,
212    /// `coordsys` is none of `XYZ`, `UTM`, `LOC…`.
213    #[error(
214        "Must specify XYZ, UTM or LOC coordinate system in antenna file header (coordsys={value})"
215    )]
216    UnknownCoordinateSystem {
217        /// The `coordsys` value.
218        value: String,
219    },
220    /// Local coordinates with neither a known observatory nor `COFA`.
221    #[error(
222        "To use local coordinates in the antenna position file, you must either use a known \
223         observatory name, or provide the COFA explicitly"
224    )]
225    LocalNeedsObservatory,
226    /// UTM without `zone`.
227    #[error("You must specify zone=NN in your antenna file")]
228    MissingZone,
229    /// A `zone` that is not an integer.
230    #[error("You must specify zone=NN in your antenna file (zone={value})")]
231    InvalidZone {
232        /// The `zone` value.
233        value: String,
234    },
235    /// UTM without `datum`.
236    #[error("You must specify datum in your antenna file")]
237    MissingDatum,
238    /// A datum code that is not in [`geodesy::DATUMS`].
239    #[error("unknown datum {code}")]
240    UnknownDatum {
241        /// The `datum` value.
242        code: String,
243    },
244    /// UTM without `hemisphere`, or with an empty one.
245    #[error("You must specify hemisphere=N|S in your antenna file")]
246    MissingHemisphere,
247    /// A `COFA` that is not `longitude,latitude`.
248    #[error("COFA must be longitude,latitude in degrees (COFA={value})")]
249    InvalidCofa {
250        /// The `COFA` value.
251        value: String,
252    },
253    /// An unknown observatory with no antennas to place it by.
254    #[error("Cannot place an unknown observatory without COFA: the file has no antennas")]
255    NoAntennas,
256    /// The measures provider failed.
257    #[error("Could not look up or convert observatory '{telescope}': {source}")]
258    Measures {
259        /// The telescope name.
260        telescope: String,
261        /// The provider's error.
262        source: MeasureError,
263    },
264}

266/// Read an antenna configuration file (CASA's `simutil.readantenna`).
267///
268/// `measures` supplies the observatory table. See the [module
269/// docs](self) for the format, the rules and the differences from CASA.
270///
271/// # Errors
272///
273/// [`ReadAntennaError::Io`] when the file cannot be read as UTF-8 text, and
274/// otherwise as [`read_antenna_config_str`].
275pub fn read_antenna_config(
276    path: &Path,
277    measures: &dyn MeasuresProvider,
278) -> Result<AntennaConfigFile, ReadAntennaError> {
279    tracing::info!("Reading antenna positions from '{}'", path.display());
280    let contents = std::fs::read_to_string(path).map_err(|source| ReadAntennaError::Io {
281        path: path.to_path_buf(),
282        source,
283    })?;
284    read_antenna_config_str(&contents, measures).map_err(|error| match error {
285        ReadAntennaError::InvalidNumber {
286            path: None,
287            line,
288            value,
289        } => ReadAntennaError::InvalidNumber {
290            path: Some(path.to_path_buf()),
291            line,
292            value,
293        },
294        error => error,
295    })
296}

298/// CASA's `Could not read file: '<path>'`, with the line and the text.
299fn invalid_number_message(path: Option<&Path>, line: &usize, value: &str) -> String {
300    let file = path.map_or_else(String::new, |path| format!(" '{}':", path.display()));
301    format!("Could not read file:{file} line {line}: could not convert string to float: '{value}'")
302}

304/// Read an antenna configuration from its text; [`read_antenna_config`]
305/// without the file.
306///
307/// # Errors
308///
309/// - [`ReadAntennaError::InvalidNumber`] for an antenna column that is not
310///   a number;
311/// - [`ReadAntennaError::MissingCoordinateSystem`] and
312///   [`ReadAntennaError::UnknownCoordinateSystem`] for `coordsys`;
313/// - [`ReadAntennaError::InvalidCofa`] for `COFA`;
314/// - [`ReadAntennaError::LocalNeedsObservatory`] for local coordinates
315///   without an observatory position;
316/// - the `Missing…`/`Invalid…`/`UnknownDatum` variants for the UTM headers;
317/// - [`ReadAntennaError::NoAntennas`] when an unknown observatory must be
318///   placed by antennas the file does not have;
319/// - [`ReadAntennaError::Measures`] when the provider fails.
320pub fn read_antenna_config_str(
321    contents: &str,
322    measures: &dyn MeasuresProvider,
323) -> Result<AntennaConfigFile, ReadAntennaError> {
324    let parsed = parse::parse_config(contents)?;
325    let coordinates = coordinate_system(&parsed.header)?;
326    let telescope = parsed
327        .header
328        .get("observatory")
329        .cloned()
330        .unwrap_or_else(|| SIMULATED_TELESCOPE.to_string());
331    let known = catalog_observatory(&telescope, measures)?;
332
333    let placed = if let Some(cofa) = parsed.header.get("COFA") {
334        if known.is_some() {
335            tracing::warn!(
336                "antenna config file specifies COFA for a known observatory {telescope}, \
337                 overriding with specified COFA."
338            );
339        }
340        Some((cofa_position(cofa)?, ObservatorySource::Cofa))
341    } else if let Some(position) = known {
342        Some((position, ObservatorySource::Catalog))
343    } else if coordinates == ConfigCoordinates::Local {
344        return Err(ReadAntennaError::LocalNeedsObservatory);
345    } else {
346        None
347    };
348
349    let (x, y, z) = match (coordinates, &placed) {
350        (ConfigCoordinates::Xyz, _) => (parsed.x, parsed.y, parsed.z),
351        (ConfigCoordinates::Utm, _) => utm_positions(&parsed)?,
352        (ConfigCoordinates::Local, Some((observatory, _))) => local_positions(&parsed, observatory),
353        (ConfigCoordinates::Local, None) => return Err(ReadAntennaError::LocalNeedsObservatory),
354    };
355    let (observatory, observatory_source) = match placed {
356        Some(placed) => placed,
357        None => (
358            mean_position(&x, &y, &z)?,
359            ObservatorySource::MeanAntennaPosition,
360        ),
361    };
362
363    Ok(AntennaConfigFile {
364        x,
365        y,
366        z,
367        dish_diameter: parsed.diameter,
368        pad_names: parsed.pad_names,
369        antenna_names: parsed.antenna_names,
370        telescope,
371        observatory,
372        observatory_source,
373        coordinates,
374        header: parsed.header,
375    })
376}

378/// `coordsys`, upper-cased: `XYZ` or `UTM` exactly, or starting `LOC`.
379fn coordinate_system(
380    header: &BTreeMap<String, String>,
381) -> Result<ConfigCoordinates, ReadAntennaError> {
382    let value = header
383        .get("coordsys")
384        .ok_or(ReadAntennaError::MissingCoordinateSystem)?;
385    let upper = value.to_uppercase();
386    if upper == "XYZ" {
387        Ok(ConfigCoordinates::Xyz)
388    } else if upper == "UTM" {
389        Ok(ConfigCoordinates::Utm)
390    } else if upper.chars().take(3).eq("LOC".chars()) {
391        Ok(ConfigCoordinates::Local)
392    } else {
393        Err(ReadAntennaError::UnknownCoordinateSystem {
394            value: value.clone(),
395        })
396    }
397}

399/// The telescope's position from the provider's table, in WGS 84, as
400/// casacore's `MeasTable::Observatory` finds it: an exact
401/// (case-insensitive) match, else the single table name that is a proper
402/// prefix of the telescope name.
403fn catalog_observatory(
404    telescope: &str,
405    measures: &dyn MeasuresProvider,
406) -> Result<Option<MPosition>, ReadAntennaError> {
407    let failed = |source| ReadAntennaError::Measures {
408        telescope: telescope.to_string(),
409        source,
410    };
411    let lookup = |name: &str| MPosition::from_observatory_name(name, measures).map_err(failed);
412    let position = match lookup(telescope)? {
413        Some(position) => Some(position),
414        None => {
415            let mut matches = Vec::new();
416            for (end, _) in telescope.char_indices().skip(1) {
417                let prefix = &telescope[..end];
418                // Providers trim their queries; a prefix ending in white
419                // space would match the shorter name a second time.
420                if prefix.trim() != prefix {
421                    continue;
422                }
423                if let Some(position) = lookup(prefix)? {
424                    matches.push(position);
425                }
426            }
427            if matches.len() == 1 {
428                matches.pop()
429            } else {
430                None
431            }
432        }
433    };
434    position
435        .map(|position| position.convert_to(PositionRef::WGS84).map_err(failed))
436        .transpose()
437}

439/// `COFA=lon,lat` in degrees, at height zero.
440fn cofa_position(value: &str) -> Result<MPosition, ReadAntennaError> {
441    let invalid = || ReadAntennaError::InvalidCofa {
442        value: value.to_string(),
443    };
444    let mut parts = value.split(',');
445    let longitude = parts
446        .next()
447        .and_then(parse::python_float)
448        .ok_or_else(invalid)?;
449    let latitude = parts
450        .next()
451        .and_then(parse::python_float)
452        .ok_or_else(invalid)?;
453    Ok(MPosition::new_wgs84(
454        longitude.to_radians(),
455        latitude.to_radians(),
456        0.0,
457    ))
458}

460type Positions = (Vec<f64>, Vec<f64>, Vec<f64>);
461
462/// UTM easting, northing, elevation to ITRF.
463fn utm_positions(parsed: &parse::ParsedConfig) -> Result<Positions, ReadAntennaError> {
464    let header = &parsed.header;
465    let zone = header.get("zone").ok_or(ReadAntennaError::MissingZone)?;
466    let datum = header.get("datum").ok_or(ReadAntennaError::MissingDatum)?;
467    let hemisphere = header
468        .get("hemisphere")
469        .and_then(|value| value.chars().next())
470        .ok_or(ReadAntennaError::MissingHemisphere)?;
471    let south = hemisphere.to_uppercase().eq(['S']);
472    let zone = parse::python_int(zone).ok_or_else(|| ReadAntennaError::InvalidZone {
473        value: zone.clone(),
474    })?;
475    let datum = geodesy::datum(datum).ok_or_else(|| ReadAntennaError::UnknownDatum {
476        code: datum.clone(),
477    })?;
478    tracing::info!(
479        "Antenna locations in UTM; will read from file easting, northing, elevation in m"
480    );
481    Ok(convert_rows(parsed, |row| {
482        geodesy::utm_to_xyz(row[0], row[1], row[2], zone, datum, south)
483    }))
484}

486/// Local east, north, up offsets to ITRF about the observatory.
487fn local_positions(parsed: &parse::ParsedConfig, observatory: &MPosition) -> Positions {
488    // CASA converts the observatory's WGS 84 angles to degrees for
489    // locxyz2itrf, which converts them back.
490    let [longitude, latitude, height] = observatory.values();
491    let (latitude_deg, longitude_deg) = (latitude.to_degrees(), longitude.to_degrees());
492    convert_rows(parsed, |row| {
493        geodesy::local_to_itrf(latitude_deg, longitude_deg, height, row)
494    })
495}
496
497fn convert_rows(parsed: &parse::ParsedConfig, convert: impl Fn([f64; 3]) -> [f64; 3]) -> Positions {
498    let mut positions = (
499        Vec::with_capacity(parsed.x.len()),
500        Vec::with_capacity(parsed.x.len()),
501        Vec::with_capacity(parsed.x.len()),
502    );
503    for ((&x, &y), &z) in parsed.x.iter().zip(&parsed.y).zip(&parsed.z) {
504        let [x, y, z] = convert([x, y, z]);
505        positions.0.push(x);
506        positions.1.push(y);
507        positions.2.push(z);
508    }
509    positions
510}

512/// The mean ITRF antenna position in WGS 84 (CASA's evident intent).
513fn mean_position(x: &[f64], y: &[f64], z: &[f64]) -> Result<MPosition, ReadAntennaError> {
514    if x.is_empty() {
515        return Err(ReadAntennaError::NoAntennas);
516    }
517    let count = x.len() as f64;
518    let mean = |values: &[f64]| values.iter().sum::<f64>() / count;
519    let (longitude, latitude, height) =
520        geodesy::xyz_to_geodetic(mean(x), mean(y), mean(z), &geodesy::WGS84)
521            .expect("the WGS 84 ellipsoid is valid");
522    Ok(MPosition::new_wgs84(longitude, latitude, height))
523}
