Expand description

Stage a locked table for replacement, sharing selected regular files at its root that the staged operation will leave unchanged.

The original tree must stay locked until publication or removal of the stage. The caller must select only data payloads that will retain their bytes and metadata throughout staging. When a link cannot be created, copy the file instead. Subtables and table locks are copied independently.

§Errors

Returns an error for unreadable, unsupported or uncopyable entries. After failure the caller owns any partial destination.
