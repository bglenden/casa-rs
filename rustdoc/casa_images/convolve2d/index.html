Module convolve2d 

Source
Expand description

Convolving an image’s direction planes with a Gaussian, as the image tool’s convolve2d does (CASA’s Image2DConvolver).

simutil.convimage convolves a Jy/pixel sky model with the clean beam to compare it with the clean image. For an image in Jy/pixel, or any flux per pixel, CASA’s rules (Image2DConvolver::_dealWithRestoringBeam) are:

  • the kernel is the Gaussian at unit peak, unscaled, so a point of 1 Jy/pixel becomes a peak of 1 Jy/beam;
  • the output is in Jy/beam, with the Gaussian as its restoring beam.

The kernel is sampled on a square of an odd number of pixels: ±5σ of the wider axis, rounded as Image2DConvolver::_sizeOfGaussian rounds it. It is centred on the middle pixel, with the beam’s position angle (north through east) turned into the pixel frame at the reference pixel. The convolution is linear (casacore’s LatticeConvolver with ConvEnums::LINEAR): the plane is padded with zeros, so flux does not wrap around the edges, and the output has the input’s shape. Masked pixels count as zero, and the output keeps the input’s mask.

As in CASA, the pixels must be square. Images in other units (Jy/beam, whose beam CASA convolves numerically, or none, whose kernel it scales to unit volume) are refused: the simulation tasks convolve Jy/pixel images only.
