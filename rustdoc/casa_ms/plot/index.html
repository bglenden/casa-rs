Module plot 

Source
Expand description

Shared plot specification and typed payload building for listobs metadata plots plus curated raw MeasurementSet visibility plots analogous to the common CASA plotms views.

The payloads are typed plot data, not pictures: Python renders them with Matplotlib, and msexplore/plotms can write them as a text point manifest. PNG and PDF rasterisation was removed (#833).
