Expand description

CASA’s includepix, an inclusive range of the pixel values a moment reads: -1 (or []) includes every pixel; one value b is [-|b|, |b|]; two values are the range’s ends, in either order (casacore’s MomentsBase::setInExCludeRange; CASA 6.7.6.14 runs includepix=-2 as [-2, 2] and [5, 2] as [2, 5]).
