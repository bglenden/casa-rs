Struct RealFft2

pub struct RealFft2<T: FftScalar> { /* private fields */ }
Expand description

Reusable in-place rank-two real/Hermitian FFTW transforms.

The caller owns shape[0] * (shape[1] / 2 + 1) complex values. Before a forward transform and after an inverse, interpret that allocation as real scalars with row stride 2 * (shape[1] / 2 + 1), ignoring end-of-row padding. In frequency space it is a contiguous Hermitian half-spectrum, reduced on the last axis. Both directions are unnormalized. Callers preserve Hermitian boundary constraints when modifying the spectrum before an inverse.

Planning, caching, alignment and worker-thread settings are shared with Fft2, but real and complex plans have distinct cache keys.
