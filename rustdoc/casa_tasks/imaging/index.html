casa_tasks

Module imaging 

Source
Expand description

The task surface of native CASA-RS imaging, on the shared task front end (#931).

The front end resolves tclean parameters through the contracts catalog: command-line flags and --json-run requests become the same resolved values, and those values, and nothing else, make the ImagingRequest the application runs, read as CASA’s modes read them (ImagingRequest::from_tclean). A run’s reply carries its ImagerRunTaskResult, and returns CASA’s summary record (tclean_record).

The environment variable that asks the casars-imager binary for its run summary.
