Struct WeightingOperatorContract 

Source 
pub struct WeightingOperatorContract { /* private fields */ }
Expand description

Positive-semidefinite data metric W and its compiler-owned commitment.

Callers cannot construct a weighting operator with a snapshot or source generation different from the compiled problem inputs.

ⓘ
use casa_imaging_model::WeightingOperatorContract;

let _ = WeightingOperatorContract::new();
