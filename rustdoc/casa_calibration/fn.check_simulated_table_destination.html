pub fn check_simulated_table_destination(
    measurement_set: &Path,
    output: &Path,
) -> Result<(), CalibrationTableWriteError>
Expand description

Refuse output as a simulated table of the MeasurementSet at measurement_set when it is that MeasurementSet, lies inside it (a subtable), or contains it: replacing it would remove the data the table is written from. Paths are compared after resolving symbolic links and .. in the part of each that exists, so an alias is caught as well.
