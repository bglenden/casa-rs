Expand description

unique_prefix_index over any items, each named by name: the position of the item input names, as MUString::minimaxNC finds it. casacore’s MeasTable finds observatories, sources and spectral lines by name this way, so ALM and ALMAX are ALMA, and VL is neither VLA nor VLBA. Spaces are part of a name: ALMA agrees with ALMA over its four characters, ALMA does not.
