Crate casa_imaging_application 

Source
Expand description

Production composition owner for native imaging.

This crate is the single application-layer seam: it compiles an ImagingRequest against its MeasurementSet, checks the installed implementation can run it, and runs it on the execution runtime. Frontends submit requests here; they do not compose native execution stages directly.
