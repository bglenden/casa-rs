Expand description

Read a visibility record for a logical set of rows. Complex and float operations retain the precision of the stored cells. With average, visibility products are reduced using flags and each row and correlation’s weight before amplitude or phase projection. With a baseline axis, each antenna pair is reduced over time. Contiguous groups of logical rows can reuse open plain members supplied in concatenation order. Other views use the table’s persisted row projection.

§Errors

A requested column cannot be read as a rectangular array.
