Expand description

Replace WEIGHT and SIGMA on the selected rows. The legacy iterator forms one group from consecutive chunks at the same integration time, and fits independent scatter estimates for every recorded baseline and correlation. Input flags participate in the fit and remain unchanged.

Returns false when the selection contains no visibility rows. The caller holds the MAIN-table write locks throughout selection, fitting, and write. An invalid selector, incompatible shape, or storage failure is an error.
