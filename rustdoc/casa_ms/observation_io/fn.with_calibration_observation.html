Expand description

Run a caltable consumer using one admitted observation opening. An MSv2 supplies its stored subtable row numbers. An MSv4 supplies the same namespace an MSv2 conversion would persist. admit_msv2 may refuse an MSv2 from its retained table descriptions before the observation indexes rows or reads subtables.

§Errors

When the observation is unreadable, the namespace cannot be represented as CASA subtables, or the read would exceed the observation budget.
