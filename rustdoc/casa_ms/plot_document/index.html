Module plot_document 

Source
Expand description

Typed MeasurementSet plot documents for renderers outside Rust.

build_measurement_set_plot plans one msexplore preset (MsPlotPreset) over a MeasurementSet and returns a MeasurementSetPlot: a renderer-neutral PlotDocument of panels, axes and layers, with the metadata a renderer shows beside it.

A document is either one panel, held in its top-level axes, layers and annotations, or a list of PlotDocumentPanels. Each PlotDocumentLayer is a point cloud (scatter samples, antenna positions) or a set of intervals (scan and spectral-window lanes); the layer’s PlotPayloadStrategy says which of its arrays are filled.

The Python package renders these documents with Matplotlib (ADR-0017 item 3). The types serialize with serde, so a task can return a document in its reply, and they depend on no binding crate.
