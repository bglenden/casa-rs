Crate casa_numerics 

Source
Expand description

Shared numerical algorithms, and CASA’s common primary-beam patterns (PBMath’s Airy and EVLA beams, chosen by telescope name: PrimaryBeam), which the simulator’s prediction and single-dish gridding both use.

Weighted polynomial fits for one visibility row and correlation component.
