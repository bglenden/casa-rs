Expand description

Append MS tool messages in one write to the linked HISTORY table. An empty message produces a record only when a CLI command was supplied.

If HISTORY is absent at a plain MS, create and link the standard table together with the first messages. Supply any write locks already held by this attachment, by canonical path.

§Errors

MAIN or HISTORY is missing, unreadable, read-only, has invalid metadata, or cannot be locked for the requested update.
