casa_coordinates

Module defaults 

Source
Expand description

Default coordinate systems, a port of casacore’s CoordinateUtil (coordinates/Coordinates/CoordinateUtil.cc).

CASA builds an image’s coordinate system from these when a script gives none (ia.fromshape, ia.fromarray), and coordsys.newcoordsys adds these coordinates. They are casacore’s: a J2000 SIN direction at the origin with 1 arcmin pixels, Stokes I, Q, U and V as the axis length allows, an LSRK frequency of 1415 MHz in 1 kHz channels with the HI line as rest frequency, and linear axes in km.

Constants§

HI_REST_FREQUENCY_HZ
The HI line’s rest frequency in Hz, casacore’s QC::HI() (1420.405751786 MHz) as CASA 6.7.6.14 reports it in Hz after casacore’s unit conversion, coordsys.newcoordsys(spectral=True) then restfrequency(): 1420405751.7860003, one ulp above the literal.

Functions§

coordinate_system_for_shape
The coordinate system casacore’s CoordinateUtil::makeCoordinateSystem makes for an image of shape, with obs_info.
direction_coordinate
The default direction coordinate, casacore’s addDirAxes: J2000, SIN, the reference at RA 0 and Dec 0 on pixel (0, 0), increments of -1 and +1 arcmin, presented in arcmin. The coordinate trait still returns its values and increments in radians.
linear_coordinate
The default linear coordinate over axes names, casacore’s addLinearAxes: reference value 0 and increment 1 in km on each axis, the reference pixel (length + 1) / 2 (integer division) of each axis when shape gives one length per name, else 0.
obs_info
The observation information casacore’s makeCoordinateSystem attaches: observer Karl Jansky, telescope ALMA, observed 2000-01-01 00:00:00.0001 UTC. casacore also sets the telescope’s position from its observatory table; that needs the measures data, so callers that have it add it.
spectral_coordinate
The default spectral coordinate, casacore’s addFreqAxis: LSRK frequency, 1415 MHz at pixel 0, 1 kHz channels, the HI line as rest frequency.
stokes_coordinate
The default Stokes coordinate for an axis of length pixels, casacore’s addStokesAxis: I, then Q, U and V; None for a length outside 1 to 4.
