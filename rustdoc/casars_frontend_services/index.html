UniFFI service layer of the casa-rs Python package.

casars.parameters resolves, renders and saves task parameters through these exports, casars.tasks decodes task completions and resolves the application catalog, and casars.data builds typed MeasurementSet plot documents. scripts/generate-frontend-bindings.sh regenerates the Python module casars._frontend from this crate’s shared library.
