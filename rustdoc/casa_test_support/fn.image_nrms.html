pub fn image_nrms(reference: &Path, other: &Path) -> Result<f64, String>
Expand description

The normalized RMS difference of the image at other from the one at reference, over every pixel: rms(other − reference) / rms(reference). Pixels NaN in both (masked) are equal; a pixel NaN in one only, any infinite pixel or a difference from an all-zero reference counts as infinite, so a comparison never reads a missing value as agreement.

§Errors

When either image cannot be read, or their shapes differ.
