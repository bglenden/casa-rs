The environment variable that asks the casars-imager binary for its run summary. CASA’s tclean writes nothing beside its image products, so neither does a tclean run here (owner decision of 2026-11-02, #980); set to 1, the binary also writes <imagename>.summary.json, the run’s status, resolved parameters, backend and each phase’s time and memory, for performance tooling ([casa_imaging_application::RunSummary]).
