2//! CASA's `simutil` helpers that `simobserve` uses (simulation Phase 5,
3//! #841): CASA 6.7.6's `casatasks/src/private/simutil.py`, ported as its
4//! specification (ADR-0018).
5//!
6//! | CASA | casa-rs |
7//! |---|---|
8//! | `direction_splitter`, `isdirection`, `dir_m2s`, `wrapang` | [`direction::Directions::split`] (a string or a list), [`direction::split_direction`] (a string), [`direction::is_direction`], [`direction::format_direction`], [`direction::wrap_angle`] |
9//! | `average_direction`, `median_direction` | [`direction::average_direction`], [`direction::median_direction`] |
10//! | `calc_pointings2` (`hexagonal`, `square`, `ALMA`, `ALMA2012`) | [`pointings::calc_pointings`] |
11//! | `read_pointings`, `write_pointings` | [`pointings::read_pointings`], [`pointings::write_pointings`] |
12//! | `noisetemp`, `bandname`, `polsettings` | [`receivers::noise_temperature`], [`receivers::band_name`], [`receivers::polarization_settings`] |
13//! | `itrf2loc`, `baselineLengths`, `approxBeam` | [`baselines::itrf_to_local`], [`baselines::baseline_lengths`], [`baselines::approximate_beam`] |
14//! | `dir_s2m` | [`direction::direction_measure`] |
15//! | `modifymodel`, `flatimage`, `ia.modify`, the component-only model | [`skymodel`] |
16//!
17//! **CASA's numbers to the last bit.** Pointing lists are compared with
18//! CASA's as strings, so the arithmetic follows CASA's: every `qa` call goes
19//! through casacore's `Quantum` arithmetic
20//! ([`casa_types::quanta::casacore`]), which converts units as casacore
21//! rounds and names them as casacore names them, and numbers that CASA
22//! writes into strings and reads back (`str(x)+"arcsec"`,
23//! `'%17.12fdeg' % x`) are written and read back the same way. The tests
24//! compare a grid of CASA's outputs
25//! (`tests/data/simutil_casa.json`, from `tools/simulation/simutil_oracle.py`).
26//!
27//! **Where casa-rs differs.** CASA raises Python exceptions where these
28//! functions refuse an input; casa-rs returns [`SimutilError`]. It also
29//! departs from CASA in a few places, each recorded in
30//! `docs/CASA (C++) bugs.md`:
31//! - `calc_pointings2`'s ALMA tiling takes its default beam from
32//!   `spacing × pbcoeff × √3`, but CASA's `pbcoeff` is undefined there
33//!   (`NameError`); casa-rs uses `simobserve`'s 1.13.
34//! - `noisetemp`'s receiver lookup reads `f0[z]` before testing `z`, so
35//!   above an unknown telescope's last tabulated frequency CASA raises
36//!   `IndexError`; casa-rs keeps the last temperature. At a frequency equal
37//!   to the first entry of the table, CASA's `t0[z-1]` with `z = 0` reads the
38//!   last temperature (230 K for ALMA at 35 GHz); casa-rs reads the first.
39//! - `direction_splitter` reads its second and third fields whatever the
40//!   field count, so a direction without an epoch raises `IndexError` in
41//!   CASA; casa-rs refuses it with a message.
42//!
43//! Where CASA has no answer, casa-rs refuses: `calc_pointings2` lays out
44//! no map of more than [`pointings::MOST_POINTINGS`] pointings, where CASA
45//! runs for hours or out of memory (a spacing tiny beside the map).

58/// An input a `simutil` helper refuses. Where CASA raises its own message,
59/// the message is CASA's.
60#[derive(Debug, Clone, PartialEq, Error)]
61pub enum SimutilError {
62    /// A value that is not a quantity casacore can read.
63    #[error("can't interpret '{0}' as a CASA quantity")]
64    Quantity(String),
65    /// A direction `direction_splitter` cannot split.
66    #[error("can't interpret '{0}' as a direction")]
67    Direction(String),
68    /// A quantity of the wrong kind for its use, or casacore's arithmetic
69    /// refusing it.
70    #[error("{0}")]
71    Arithmetic(String),
72    /// A pointing file with no pointings in it.
73    #[error("No valid lines found in pointing file")]
74    NoPointings,
75    /// Fewer pointing times than pointings.
76    #[error("{times} pointing times for {pointings} pointings")]
77    Times {
78        /// The number of pointings.
79        pointings: usize,
80        /// The number of times.
81        times: usize,
82    },
83    /// A frequency that is not positive and finite.
84    #[error("frequency {0} GHz is not positive")]
85    Frequency(f64),
86    /// A map of more pointings than casa-rs lays out.
87    #[error("the map would have more than {} pointings", pointings::MOST_POINTINGS)]
88    TooManyPointings,
89}
90
91impl From<casa_types::quanta::casacore::QuantumError> for SimutilError {
92    fn from(error: casa_types::quanta::casacore::QuantumError) -> Self {
93        Self::Arithmetic(error.0)
94    }
