2//! CASA's MeasurementSet time selection: the `timerange` expressions of
3//! casacore's `MSSelection`, ported from `MSTimeGram.ll`, `MSTimeGram.yy` and
4//! `MSTimeParse.cc` at casacore `aaf72eb7`, the commit CASA 6.7.6.14 builds.
5//!
6//! [`resolve_time_selector`] turns an expression into a [`TimeSelection`]:
7//! the conditions on the MAIN `TIME` column that `MSTimeParse` builds as TaQL,
8//! with the same double-precision constants. [`TimeSelection::holds`] then
9//! tests a row's `TIME` exactly as CASA's TaQL does. `MSSelection` ANDs the
10//! time conditions with the conjunction of its other expressions, which is the
11//! caller's part.
12//!
13//! # Forms
14//!
15//! A `timerange` is one or more comma-separated terms; a row is selected when
16//! any term holds (`MSTimeParse::addCondition`, MSTimeParse.cc:188-196). With
17//! `t`, `t0`, `t1` the term's times in seconds and `e` the default row's
18//! `EXPOSURE` (see [Defaults](#defaults)):
19//!
20//! | Term | Example | Condition on `TIME` | C++ |
21//! |---|---|---|---|
22//! | `T` | `2017/03/01/09:00:00.5` | `abs(TIME - t) <= e/2` | MSTimeParse.cc:200-213 |
23//! | `>T` | `>09:59:00` | `TIME >= t` (inclusive) | MSTimeParse.cc:217-228 |
24//! | `<T` | `<09:00:10` | `TIME <= t` (inclusive) | MSTimeParse.cc:232-244 |
25//! | `T0~T1` | `09:00:00~09:01:00` | `TIME >= t0 && TIME <= t1` | MSTimeParse.cc:264-266 |
26//! | `T0+dT` | `09:00:00+00:00:10` | as `T0~T1` with `t1 = t0 + dT` | MSTimeGram.yy:164-185 |
27//! | `[T0~T1]`, `[T0+dT]` | `[09:00:00~09:01:00]` | `(TIME > t0 \|\| abs(TIME - t0) < w) && (TIME < t1 \|\| abs(TIME - t1) < w)`, `w = e/2` | MSTimeParse.cc:263, 267-270 |
28//! | `N[T0~T1]`, `N[T0+dT]` | `3.0[09:00:00~09:01:00]` | as `[T0~T1]` with `w = N` seconds | MSTimeGram.yy:148-151 |
29//!
30//! The edge width `w` is a C `Float` (`MSTimeEdgeBuffer`, `edgeWidth_l`), so
31//! it is rounded to single precision; `N` must be written with a point
32//! (`3.0[` or `3.[`), since the grammar takes only an `FNUMBER` there and
33//! `3[` is a parse error. `0.0[T0~T1]` is the open interval. A range whose
34//! lower bound exceeds its upper bound is refused (MSTimeParse.cc:256-258).
35//!
36//! Each time `T` is a date and a time of day, either of which may be missing:
37//!
38//! | Text | Fields | C++ |
39//! |---|---|---|
40//! | `Y/M/D/h:m:s` | all given | MSTimeGram.yy:215, 228-241 |
41//! | `Y/M/D/h:m:` | seconds 0 | MSTimeGram.yy:216 |
42//! | `Y/M/D/m:s` | hour 0: one colon is **minutes and seconds**, so `09:30` is 00:09:30 | MSTimeGram.yy:217 |
43//! | `Y/M/D/s:` | hour and minute 0: a lone trailing colon is **seconds** | MSTimeGram.yy:218 |
44//! | `Y/M/D/s` | a bare number is **seconds**, with the hour and minute defaulted | MSTimeGram.yy:219 |
45//! | `Y/M/D` | hour, minute, second and millisecond defaulted | MSTimeGram.yy:242-250 |
46//! | any of these without `Y/M/D/` | year, month and day defaulted | MSTimeGram.yy:251-261 |
47//! | `*` for a number | that field defaulted (`*` seconds also default the milliseconds) | MSTimeGram.yy:131-133 |
48//! | an empty field, as in `/03/01` or `:30` | 0 | MSTimeGram.yy:208, 212 |
49//! | `M/D/` (two date fields) | year 0, so refused | MSTimeGram.yy:222 |
50//!
51//! Seconds keep whole milliseconds, truncated (`splitSec`, MSTimeGram.yy:97-104):
52//! `1.001` is the double `1.000999...` and keeps 0 ms, and `2.501` keeps 500.
53//! Only the year, month (1 to 12) and day (1 to 31) are checked, with years
54//! before 1858 refused (`MSTimeParse::validate`, MSTimeParse.cc:388-411);
55//! other values roll over arithmetically, so `2017/02/29` is March 1 and
56//! `08:59:60.5` is 09:00:00.5.
57//!
58//! In `T0~T1`, every field missing from `T1` is copied from `T0` once `T0`
59//! has its defaults (`copyDefaults`), so `09:00:00~10:00:00` is on one day and
60//! `23:00:00~01:00:00` is refused. In `T0+dT`, `dT` is read as a time with
61//! the MJD epoch's defaults (1858/11/17, zero time of day) and its MJD is
62//! added to `T0`'s in `MVEpoch` day arithmetic, so `+10` is 10 s, `+1:00` is
63//! one minute and `+48:00:00` two days. There are no numeric MJD forms, units
64//! or signs: `57813.375`, `10s`, `-` and `2017-03-01` are parse errors.
65//! Spaces, tabs and newlines between tokens are ignored, but only the empty
66//! string selects everything; a blank expression is a parse error, as in CASA.
67//!
68//! # Defaults
69//!
70//! Each term reads its defaults from one MAIN row
71//! (`MSTimeParse::getDefaults`, MSTimeParse.cc:114-184): the row's `TIME`,
72//! split into year, month and day by `MVTime` and into hour, minute and second
73//! by casacore's `Time`, with the milliseconds `(Int)((t0 - t1) * 1E3)`
74//! truncated, and the row's `EXPOSURE` (`e`). On `MSSelection`'s path the
75//! first term reads the first logical row ([`msselection_first_logical_row`])
76//! and every later term reads row 0: `getDefaults` searches only on its first
77//! call and otherwise keeps `firstLogicalRow = 0` (MSTimeParse.cc:116-120).
78//! [`TimeSelectorDefaults`] carries both rows.
79//!
80//! # Time scale
81//!
82//! The expression's times are compared with `TIME` in whatever scale `TIME`
83//! holds. `MSTimeParse::toTAIInSec` (MSTimeParse.cc:339-344) despite its name
84//! converts nothing (its `MEpoch::Convert` to TAI is commented out), so a UTC
85//! `TIME` column is selected by UTC times, with no leap-second offset.
86//!
87//! # Not ported
88//!
89//! The grammar keeps the bracket state in process globals that a failed parse
90//! inside brackets leaves set, so CASA's next unbracketed range in the same
91//! process is edge-inclusive; each parse here starts afresh. A seconds value
92//! or a year beyond C `Int` arithmetic, and a default row whose `TIME` is not
93//! a finite day number, are undefined behaviour in the C++ and are refused.
94//!
95//! # Evidence
96//!
97//! `resources/casa-compat/evidence/msselection-time-casa-20261102.json` holds
98//! the rows CASA 6.7.6.14's `ms.msselect` keeps for 1528 expressions (curated
99//! forms, seeded random ones, first-logical-row and later-term defaults, and
100//! defaults rebuilt from assorted sub-second row times), written by
101//! `tools/casa-compat/time_selection_oracle.py`; the tests replay every one.

110/// The `TIME` and `EXPOSURE` of the MAIN row a time expression takes its
111/// defaults from.
112#[derive(Debug, Clone, Copy, PartialEq)]
113pub struct TimeDefaults {
114    /// The row's `TIME`: seconds since MJD 0 in the column's own time scale
115    /// (normally UTC), as the MeasurementSet stores it with unit `s`.
116    pub time_mjd_s: f64,
117    /// The row's `EXPOSURE` in seconds. Half of it is a single time's
118    /// tolerance and a bracketed range's edge width.
119    pub exposure_s: f64,
120}

122/// The rows a whole time expression takes its defaults from.
123///
124/// CASA reads the first comma-separated term's defaults from the first
125/// logical row and every later term's from row 0 (MSTimeParse.cc:116-120),
126/// a CASA quirk this port keeps. When both are the same row,
127/// `TimeSelectorDefaults::from(defaults)` fills both.
128#[derive(Debug, Clone, Copy, PartialEq)]
129pub struct TimeSelectorDefaults {
130    /// The first logical row's values, for the first term; see
131    /// [`msselection_first_logical_row`].
132    pub first_term: TimeDefaults,
133    /// Row 0's values, for every later term.
134    pub later_terms: TimeDefaults,
135}
136
137impl From<TimeDefaults> for TimeSelectorDefaults {
138    fn from(defaults: TimeDefaults) -> Self {
139        Self {
140            first_term: defaults,
141            later_terms: defaults,
142        }
143    }
144}

146/// The predicate `MSSelection` uses to find the first logical row.
147///
148/// `MSSelection::toTableExprNode` parses the time expression last, passing
149/// the conjunction of every other expression as `otherTens`, and constructs
150/// `MSTimeParse` with `honourRowFlags` at its default of true
151/// (MSSelection.cc:729-744, MSTimeGram.cc:112-118, MSTimeParse.h:97-100).
152pub enum LogicalRowFilter<'a> {
153    /// No other expression is set (`otherTens` is null): the closure returns
154    /// a row's `FLAG_ROW`, and the first row not flagged is the first logical
155    /// row (MSTimeParse.cc:136-146).
156    FlagRow(&'a mut dyn FnMut(usize) -> bool),
157    /// Another expression is set: the closure returns whether the other
158    /// expressions together select a row, and the first such row is the first
159    /// logical row. `FLAG_ROW` is not consulted here, since both branches of
160    /// CASA's flag test read the same condition (MSTimeParse.cc:122-135).
161    OtherSelections(&'a mut dyn FnMut(usize) -> bool),
162}
163
164/// The first logical row `MSSelection` reads time defaults from, among
165/// `row_count` MAIN rows.
166///
167/// It is the first row `filter` accepts, or row 0 when it accepts none.
168/// [`TimeSelectorDefaults::first_term`] takes that row's `TIME` and
169/// `EXPOSURE`, and [`TimeSelectorDefaults::later_terms`] row 0's. Find it only
170/// for a non-empty expression: CASA reads no defaults for an empty one.
171///
172/// # Errors
173///
174/// An empty MAIN table has no logical row zero (MSTimeParse.cc:147-149).
175pub fn msselection_first_logical_row(
176    row_count: usize,
177    filter: LogicalRowFilter<'_>,
178) -> MsResult<usize> {
179    if row_count == 0 {
180        return Err(MsError::InvalidInput(
181            "MSTimeParse: No logical \"row zero\" found for time selection".to_string(),
182        ));
183    }
184    let found = match filter {
185        LogicalRowFilter::FlagRow(flag_row) => (0..row_count).find(|&row| !flag_row(row)),
186        LogicalRowFilter::OtherSelections(selected) => (0..row_count).find(|&row| selected(row)),
187    };
188    Ok(found.unwrap_or(0))
189}

191/// One condition on a row's `TIME`, as `MSTimeParse` builds it in TaQL.
192/// Every time is in seconds in the `TIME` column's scale.
193#[derive(Debug, Clone, Copy, PartialEq)]
194pub enum TimeCondition {
195    /// `abs(TIME - time_s) <= tolerance_s`, a single time with half the
196    /// default exposure (MSTimeParse.cc:200-213).
197    Near {
198        /// The time.
199        time_s: f64,
200        /// Half the default row's `EXPOSURE`.
201        tolerance_s: f64,
202    },
203    /// `TIME >= time_s`, from `>T` (MSTimeParse.cc:217-228).
204    AtOrAfter {
205        /// The bound.
206        time_s: f64,
207    },
208    /// `TIME <= time_s`, from `<T` (MSTimeParse.cc:232-244).
209    AtOrBefore {
210        /// The bound.
211        time_s: f64,
212    },
213    /// `TIME >= lower_s && TIME <= upper_s`, from `T0~T1` or `T0+dT`
214    /// (MSTimeParse.cc:264-266).
215    Within {
216        /// The lower bound.
217        lower_s: f64,
218        /// The upper bound.
219        upper_s: f64,
220    },
221    /// `(TIME > lower_s || abs(TIME - lower_s) < edge_s) && (TIME < upper_s
222    /// || abs(TIME - upper_s) < edge_s)`, from a bracketed range
223    /// (MSTimeParse.cc:267-270).
224    EdgeInclusive {
225        /// The lower bound.
226        lower_s: f64,
227        /// The upper bound.
228        upper_s: f64,
229        /// The edge width, a C `Float`: half the default exposure, or `N`.
230        edge_s: f32,
231    },
232}
233
234impl TimeCondition {
235    /// Whether a row whose `TIME` is `time_s` meets the condition, with the
236    /// same double-precision operations as CASA's TaQL.
237    #[must_use]
238    pub fn holds(&self, time_s: f64) -> bool {
239        match *self {
240            Self::Near {
241                time_s: centre,
242                tolerance_s,
243            } => (time_s - centre).abs() <= tolerance_s,
244            Self::AtOrAfter { time_s: bound } => time_s >= bound,
245            Self::AtOrBefore { time_s: bound } => time_s <= bound,
246            Self::Within { lower_s, upper_s } => time_s >= lower_s && time_s <= upper_s,
247            Self::EdgeInclusive {
248                lower_s,
249                upper_s,
250                edge_s,
251            } => {
252                let edge = f64::from(edge_s);
253                (time_s > lower_s || (time_s - lower_s).abs() < edge)
254                    && (time_s < upper_s || (time_s - upper_s).abs() < edge)
255            }
256        }
257    }
258}

282/// A resolved `timerange`: the OR of its terms, or every row when the
283/// expression was empty.
284#[derive(Debug, Clone, Default, PartialEq)]
285pub struct TimeSelection {
286    terms: Box<[TimeTerm]>,
287}
288
289impl TimeSelection {
290    /// The selection of an empty expression, which puts no condition on `TIME`.
291    #[must_use]
292    pub fn all() -> Self {
293        Self::default()
294    }
295
296    /// Whether the selection puts no condition on `TIME`.
297    #[must_use]
298    pub fn selects_all(&self) -> bool {
299        self.terms.is_empty()
300    }
301
302    /// Whether a row whose `TIME` is `time_s` is selected: any term holds,
303    /// or the expression was empty.
304    #[must_use]
305    pub fn holds(&self, time_s: f64) -> bool {
306        self.terms.is_empty() || self.terms.iter().any(|term| term.condition.holds(time_s))
307    }
308
309    /// The resolved terms, in the expression's order.
310    #[must_use]
311    pub fn terms(&self) -> &[TimeTerm] {
312        &self.terms
313    }
314
315    /// `MSSelection::getTimeList()`, one entry per term.
316    pub fn time_list(&self) -> impl ExactSizeIterator<Item = TimeListEntry> + '_ {
317        self.terms.iter().map(|term| term.time_list_entry)
318    }
319
320    /// Heap bytes the selection holds: exactly one [`TimeTerm`] per term, and
321    /// nothing for an empty expression.
322    #[must_use]
323    pub fn allocated_bytes(&self) -> usize {
324        std::mem::size_of_val::<[TimeTerm]>(&self.terms)
325    }
326}

328/// A parsed `timerange` expression whose defaults are not yet applied.
329///
330/// Parsing needs no MeasurementSet, so a caller can refuse a malformed
331/// expression, and skip finding the default rows for an empty one, before it
332/// reads any rows. Errors CASA finds in a term's actions (a bad date, a
333/// reversed range) appear at [`resolve`](Self::resolve); where an expression
334/// has both, CASA may report whichever its parser reaches first.
335#[derive(Debug, Clone, Default, PartialEq)]
336pub struct TimeSelector {
337    terms: Box<[TermSyntax]>,
338}
339
340impl TimeSelector {
341    /// Parse `text`. The empty string selects every row; any other text,
342    /// blank text included, must be a valid expression.
343    ///
344    /// # Errors
345    ///
346    /// A parse error, with CASA's message naming the token and position.
347    pub fn parse(text: &str) -> MsResult<Self> {
348        if text.is_empty() {
349            return Ok(Self::default());
350        }
351        Ok(Self {
352            terms: grammar::parse(text)?.into_boxed_slice(),
353        })
354    }
355
356    /// Whether the expression was empty, which selects every row and reads
357    /// no defaults.
358    #[must_use]
359    pub fn selects_all(&self) -> bool {
360        self.terms.is_empty()
361    }
362
363    /// The number of comma-separated terms.
364    #[must_use]
365    pub fn term_count(&self) -> usize {
366        self.terms.len()
367    }
368
369    /// Apply the defaults and resolve each term's condition.
370    ///
371    /// # Errors
372    ///
373    /// A year before 1858, a month outside 1 to 12 or a day outside 1 to 31
374    /// (CASA's `MSTime Selection error`), a range whose lower bound exceeds
375    /// its upper bound, or a default row or field beyond the arithmetic CASA
376    /// defines.
377    pub fn resolve(&self, defaults: impl Into<TimeSelectorDefaults>) -> MsResult<TimeSelection> {
378        let defaults = defaults.into();
379        let terms = self
380            .terms
381            .iter()
382            .enumerate()
383            .map(|(index, syntax)| {
384                let row = if index == 0 {
385                    defaults.first_term
386                } else {
387                    defaults.later_terms
388                };
389                let row = clock::row_defaults(row.time_mjd_s, row.exposure_s).ok_or_else(|| {
390                    MsError::InvalidInput(format!(
391                        "MSTimeParse: default row TIME {} s is outside the days casacore's \
392                         Time converts",
393                        row.time_mjd_s
394                    ))
395                })?;
396                resolve_term(*syntax, &row, index + 1)
397            })
398            .collect::<MsResult<Box<[TimeTerm]>>>()?;
399        Ok(TimeSelection { terms })
400    }
401}

403/// Parse and resolve a `timerange` expression; see the [module
404/// documentation](self) for the forms and defaults.
405///
406/// Pass a [`TimeDefaults`] when the first logical row is row 0, and a
407/// [`TimeSelectorDefaults`] otherwise.
408///
409/// # Errors
410///
411/// As [`TimeSelector::parse`] and [`TimeSelector::resolve`].
412pub fn resolve_time_selector(
413    text: &str,
414    defaults: impl Into<TimeSelectorDefaults>,
415) -> MsResult<TimeSelection> {
416    TimeSelector::parse(text)?.resolve(defaults)
417}

419/// The grammar action of one term with its default row (MSTimeGram.yy:137-205).
420fn resolve_term(syntax: TermSyntax, row: &RowDefaults, number: usize) -> MsResult<TimeTerm> {
421    let exposure_s = row.exposure_s;
422    let (condition, time_list_entry) = match syntax {
423        TermSyntax::Single(fields) => {
424            let time_s = time_seconds(clock::fill_from_row(fields, row))?;
425            let tolerance_s = exposure_s / 2.0;
426            (
427                TimeCondition::Near {
428                    time_s,
429                    tolerance_s,
430                },
431                listed(time_s, time_s, tolerance_s, exposure_s),
432            )
433        }
434        TermSyntax::AtOrAfter(fields) => {
435            let time_s = time_seconds(clock::fill_from_row(fields, row))?;
436            (
437                TimeCondition::AtOrAfter { time_s },
438                listed(time_s, f64::MAX, -1.0, exposure_s),
439            )
440        }
441        TermSyntax::AtOrBefore(fields) => {
442            let time_s = time_seconds(clock::fill_from_row(fields, row))?;
443            (
444                TimeCondition::AtOrBefore { time_s },
445                listed(0.0, time_s, -1.0, exposure_s),
446            )
447        }
448        TermSyntax::Range {
449            lower,
450            join,
451            upper,
452            edge,
453        } => resolve_range(lower, join, upper, edge, row, number)?,
454    };
455    Ok(TimeTerm {
456        condition,
457        time_list_entry,
458    })
459}

461/// `rangetimeexpr` and `MSTimeParse::selectTimeRange` (MSTimeGram.yy:153-185,
462/// MSTimeParse.cc:248-274).
463fn resolve_range(
464    lower: TimeFields,
465    join: RangeJoin,
466    upper: TimeFields,
467    edge: Edge,
468    row: &RowDefaults,
469    number: usize,
470) -> MsResult<(TimeCondition, TimeListEntry)> {
471    let lower = clock::fill_from_row(lower, row);
472    let (lower_s, upper_s) = match join {
473        RangeJoin::Span => {
474            let upper = fill(upper, lower);
475            (time_seconds(lower)?, time_seconds(upper)?)
476        }
477        RangeJoin::Duration => {
478            let duration = clock::fill_from_mjd_reference(upper);
479            validate(lower)?;
480            validate(duration)?;
481            let start_days = date_time(lower)?.modified_julian_day();
482            let duration_days = date_time(duration)?.modified_julian_day();
483            (
484                epoch_seconds(epoch_days(start_days, 0.0)),
485                epoch_seconds(epoch_days(start_days, duration_days)),
486            )
487        }
488    };
489    if lower_s > upper_s {
490        return Err(MsError::InvalidInput(format!(
491            "MSSelection time error: lower bound > upper bound in time selection term {number}"
492        )));
493    }
494    // `Float edgeWidth_l = (edgeWidth < 0.0) ? (edgeInclusive ?
495    // defaultExposure/2.0 : 0.0) : edgeWidth`.
496    #[expect(clippy::cast_possible_truncation, reason = "edgeWidth_l is a C Float")]
497    let (condition, width) = match edge {
498        Edge::Closed => (TimeCondition::Within { lower_s, upper_s }, 0.0_f32),
499        Edge::Exposure | Edge::Width(_) => {
500            let edge_s = match edge {
501                Edge::Width(width) => width,
502                _ => (row.exposure_s / 2.0) as f32,
503            };
504            (
505                TimeCondition::EdgeInclusive {
506                    lower_s,
507                    upper_s,
508                    edge_s,
509                },
510                edge_s,
511            )
512        }
513    };
514    Ok((
515        condition,
516        listed(lower_s, upper_s, f64::from(width), row.exposure_s),
517    ))
518}

520/// `accumulateTimeList`: a negative width records the default exposure.
521fn listed(start_s: f64, end_s: f64, width_s: f64, exposure_s: f64) -> TimeListEntry {
522    TimeListEntry {
523        start_s,
524        end_s,
525        width_s: if width_s >= 0.0 { width_s } else { exposure_s },
526    }

529/// `MSTimeParse::yearTimeConvert` then `toTAIInSec` (MSTimeParse.cc:317-344).
530fn time_seconds(fields: TimeFields) -> MsResult<f64> {
531    validate(fields)?;
532    let days = date_time(fields)?.modified_julian_day();
533    Ok(epoch_seconds(epoch_days(days, 0.0)))
534}

536fn date_time(fields: TimeFields) -> MsResult<clock::CasacoreTime> {
537    time_of(fields).ok_or_else(|| {
538        MsError::InvalidInput(format!(
539            "MSTime Selection error: Year = {} is beyond the C int day arithmetic \
540             of casacore's Time",
541            fields.year
542        ))
543    })
544}

546/// `MSTimeParse::validate` (MSTimeParse.cc:388-411).
547fn validate(fields: TimeFields) -> MsResult<()> {
548    let refusal = if fields.year < 1858 {
549        format!("Year = {}", fields.year)
550    } else if fields.month <= 0 || fields.month > 12 {
551        format!("Month = {}", fields.month)
552    } else if fields.day <= 0 || fields.day > 31 {
553        format!("Day = {}", fields.day)
554    } else {
555        return Ok(());
556    };
557    Err(MsError::InvalidInput(format!(
558        "MSTime Selection error: {refusal} out of range"
559    )))
560}
