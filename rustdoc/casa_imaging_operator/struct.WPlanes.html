Struct WPlanes 

Source 
pub struct WPlanes { /* private fields */ }
Expand description

The W-projection kernel set: one dense complex cell per w-plane, C ⋆ FT[e^{2πi w(√(1−l²−m²)−1)}] sampled four times per cell, scalar Mueller routing and the paired 1/(grdsf · sinc) correction.
