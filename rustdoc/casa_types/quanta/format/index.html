Module format 

Source
Expand description

casacore’s angle and time formatting: MVAngle::print, MVTime::print and their format names (MVAngle::giveMe, MVTime::giveMe), and MVTime’s calendar fields.

A format is a set of casacore’s formatTypes flags, such as TIME|YMD or ANGLE|DIG2. The precision counts digits as casacore counts them: 0 is the stream default, 6, so an angle prints as +ddd.mm.ss and a time as hh:mm:ss; 2 stops at degrees or hours, 4 at minutes, and each digit above 6 adds a decimal to the seconds. Values round to the last digit shown.

This is the full counterpart of the convenience formatters on MvAngle and MvTime, which keep their own precision conventions.

Divergence: LOCAL formats in UTC (a time-zone offset of zero), where casacore uses the time zone of its aipsrc or of the system.

use casa_types::quanta::format::{ANGLE, TIME, YMD, format_angle, format_time, time_format};

assert_eq!(format_angle(45.5_f64.to_radians(), ANGLE, 0), "+045.30.00");
assert_eq!(format_time(58849.5, TIME | YMD, 0), "2020/01/01/12:00:00");
assert_eq!(time_format("fits"), 2049);
