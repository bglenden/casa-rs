Module pointing_plan 

Source
Expand description

What a conversion carries of the source’s pointing, decided with the losses that implies before anything is written (plan), as the reads through the boundary ([Observation::pointing]) that carry it:

  • into an MSv4, one per partition over its own times, as XRADIO’s converter takes the POINTING rows within each dataset’s times (the boundary adds each antenna’s nearest sample either side);
  • into an MSv2, reads that gather every sample once: an MSv2 source’s rows of every named antenna, its antennas grouped so that each read fits the budget, or an MSv4 source’s datasets whole.

An MSv2 source’s POINTING is scanned once ([pointing_scan]) for what those reads cannot carry: rows nothing reads, rows a partition reads at the antenna and time of another (an MSv4 holds one sample there), polynomial terms beyond the direction (an MSv4 holds one term), and the columns neither destination holds. Pointing a read would refuse or the destination cannot hold at all (directions in several frames, a frame MSv4 has no name for, rows beyond the reader’s bound) is lost whole, as a reported loss, rather than refused part way through writing. Each read is checked against the budget with the catalog’s own bound, and an MSv2 destination’s gathered rows with the writer’s; beyond it the conversion is refused. (An MSv2 destination’s POINTING table itself is held in memory until it is saved: #950.)
