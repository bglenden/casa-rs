Expand description

Request for native flagdata.

Fields§

§selection: MsSelection

Structured row selection.

§casa_row_selection: bool

Interpret row selectors using the public CASA flagdata task grammar.

§spw: Option<String>

CASA-style SPW/channel selector.

§correlation: Option<String>

CASA agent selection of stored correlation planes.

§mode: FlagDataMode

Mode to execute.

§action: FlagDataAction

Manual action.

§autocorr: bool

Set manual flags only on rows whose antenna IDs are equal.

§data_column: FlagDataColumn

Data column for automatic modes.

§display_column_is_scalar: bool

Whether a requested display has a scalar data-column name. CASA checks this after selection and any apply backup.

§flagbackup: bool

Create a flagdata_N backup before mutating flags.

§summary_options: FlagSummaryOptions

Optional breakdowns for summary mode.

§clipzeros: bool

Clip exact zeros in FlagDataMode::Clip.

§clipminmax: Option<[f64; 2]>

Optional lower and upper values for the clip range.

§clipoutside: Option<bool>

Flag outside or inside the range. An accepted vector disables the clip agent.

§clip_channel_bins: Option<Vec<u32>>

Average selected channels before clipping or public MS TFCrop. A singleton width is used for all spectral windows. Zero passes through and one takes the whole window.

§clip_time_bin: Option<String>

Average integrations on each baseline before clipping or public MS TFCrop.

§time_chunk: Option<f64>

Positive visibility-iterator chunk interval, in seconds.

§combinescans: bool

Omit scan boundaries when grouping public TFCrop and extension rows.

§quackinterval: f64

Quack interval in seconds.

§quackmode: QuackMode

Quack scan edge.

§quackincrement: bool

Start the interval from the first or last time with unflagged data.

§elevation_limits_deg: [f64; 2]

Inclusive lower and upper antenna elevations, in degrees.

§shadow: ShadowOptions

Dish shadowing parameters.

§antint: AntennaIntegrationOptions

Reference antenna integration flagging parameters.

§timecutoff: f64

TFCrop time cutoff in robust sigma units.

§freqcutoff: f64

TFCrop frequency cutoff in robust sigma units.

§tfcrop: Option<TfcropOptions>

Fit controls for the TFCrop agent. An invalid CASA configuration can leave this agent inactive while running post-extension.

§timedevscale: f64

RFlag time threshold scale, applied to a given threshold and a computed one alike, as CASA applies it.

§freqdevscale: f64

RFlag spectral threshold scale, applied to a given threshold and a computed one alike.

§spectralmax: f64

RFlag maximum acceptable spectral standard deviation before flagging the full row spectrum.

§spectralmin: f64

RFlag minimum acceptable spectral standard deviation before flagging the full row spectrum.

§rflag_window: Option<usize>

Maximum number of time samples in an RFlag variance window. A rejected agent record disables RFlag and leaves extension available.

§rflag_calculate: Option<bool>

Direct calibration agents can calculate RFlag thresholds in a run that writes other agents’ flags, or apply thresholds in a dry run.

§automatic_average_vector: Option<&'static str>

Boolean-vector switch to reject after selecting rows and validating the column.

§timedev: Option<f64>

Optional RFlag time threshold, before Self::timedevscale. None computes one from the data.

§freqdev: Option<f64>

Optional RFlag spectral threshold, before Self::freqdevscale. None computes one from the data.

§timedev_by_field_spw: BTreeMap<(i32, i32), f64>

Explicit RFlag time thresholds keyed by field and spectral window.

§freqdev_by_field_spw: BTreeMap<(i32, i32), f64>

Explicit RFlag frequency thresholds keyed by field and spectral window.

§extendflags: bool

Run CASA’s automatic post-extension agent after TFCrop/RFlag.

§extendpols: bool

Extend flags across correlations/polarizations.

§extension_enabled: bool

Whether the public CASA values allow the extension agent to start.

§growaround: bool

Flag samples with at least five flagged neighbors.

§flagneartime: bool

Extend existing flags one integration in each time direction.

§flagnearfreq: bool

Extend existing flags one selected channel in each frequency direction.

§growtime: f64

If > 0, flag full channel time columns whose flagged percentage meets this threshold.

§growfreq: f64

If > 0, flag full row spectra whose flagged percentage meets this threshold.
