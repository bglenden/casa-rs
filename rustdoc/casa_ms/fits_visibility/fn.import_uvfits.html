Convert UVFITS visibilities, flags, weights and AIPS subtables to MSv2. The named MeasurementSet is created only after the conversion completes.

§Errors

The input cannot be read or has incompatible visibility metadata, the output already exists, or the converted MeasurementSet cannot be saved.
