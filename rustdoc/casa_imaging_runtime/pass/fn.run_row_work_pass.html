Each domain’s gridding work by anchor row over one traversal that reads flags and weights only (SampleContent::FlagsAndWeights): every row is placed as a pass places it, with weighting, and each placement adds its work, its kernel’s taps and PLACEMENT_WORK, to its anchor row (Router::owner_and_work). None for a domain of plane owners. It is what a first pass measures (super::PassSummary::row_work) without reading or gridding the visibilities, so the first pass’s strips can be cut balanced (Partition::regions_balanced). Each counted placement also adds its PSF and weight work (ModeWork), from the kernel set’s metadata. It holds row_work_pass_bytes.
