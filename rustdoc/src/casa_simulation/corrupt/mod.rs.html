2//! Visibility corruption: thermal noise, CASA's `ANoise` term
3//! (`sm.setnoise(mode='simplenoise')` then `sm.corrupt()`), and the
4//! `tsys-manual` noise that scales it per row ([`tsys`]).
5//!
6//! # What CASA adds
7//!
8//! Measured against CASA 6.7.6 (simulation Phase 1d probes, #841), each
9//! `corrupt` adds, for every noise term, to every DATA sample:
10//! - on a cross-correlation row, independent real and imaginary draws, each
11//!   N(0, σ²), where σ is the term's `simplenoise` in Jy, or for a
12//!   `tsys-manual` term the row's σ from its antennas, elevations, channel
13//!   width and integration time ([`tsys`]);
14//! - on an autocorrelation row, a real draw only: the imaginary part is
15//!   unchanged;
16//! - in every correlation, the cross-hands of four-correlation data
17//!   included, each with its own draw;
18//! - whatever the flags: flagged rows and samples get noise too.
19//!
20//! WEIGHT and SIGMA are left as observed, by both modes. CASA's
21//! `ANoiseCorruptor::simPar`
22//! draws in double precision and rounds `Complex(r·amp, i·amp)`, σ held as
23//! a `Float`, to the single precision DATA is stored in. casa-rs draws in
24//! single precision instead, and scales by σ in it too, for speed: a vector
25//! register holds four lanes rather than two and the series are about half
26//! as long. On an Apple M2 core that nearly halves the noise's cost, from
27//! 6.2 to 3.2 ns per complex sample of two-correlation rows, the generator's
28//! 1.2 ns included (#855). The difference is below what the stored `f32`
29//! resolves: against noise of standard deviation σ it is of order 10⁻⁷σ
30//! ([`casa_numerics::cell_noise`] gives the bounds and where they come
31//! from).
32//!
33//! # Where the draws come from
34//!
35//! CASA draws from one `MLCG` stream per term, in the order its visibility
36//! iterator visits rows, channels and correlations, and the stream carries on
37//! across `corrupt` calls. casa-rs keys each draw instead: the draws come
38//! from [`casa_numerics::cell_noise`] (Philox4x32-10 and Box–Muller in
39//! `f32`), whose counter is the absolute MAIN row, the channel and the
40//! correlation pair, and whose 64-bit key names the stream. This module
41//! forms the key ([`NoiseApplication`]): its first word is the term's seed
42//! (`sm.setseed`, as its 32 bits), and its second the purpose byte
43//! [`PURPOSE_THERMAL_NOISE`] above the term's application ordinal (how many
44//! `corrupt` calls the term had seen before). A `tsys-manual` term draws as
45//! a `simplenoise` term of the same seed does, scaled by its row's σ, as
46//! CASA's unit-amplitude `ANoise` is. The two schemes are
47//! statistically equivalent, not bit-identical (plan, "Random numbers"), and
48//! they share the structure scripts see:
49//! - two terms with the same seed draw the same values in the same
50//!   `corrupt`, so their noise adds coherently (variance 4σ² for two);
51//! - one term applied twice draws independent values (variance 2σ²);
52//! - a different seed draws different values.
53//!
54//! The result depends only on (seed, ordinal, row, channel, correlation) and
55//! the row's σ, so it is bitwise the same for any batch size, worker count,
56//! backend or platform; the tests hold a few cells to the bits they had
57//! before the generator moved to casa-numerics (#855).

69/// The top byte of the key's second word names what the stream is for, so
70/// later corruptions (gains, fBM screens) draw from streams disjoint from
71/// thermal noise under the same seed.
72const PURPOSE_THERMAL_NOISE: u32 = 0x01;
73
74/// Application ordinals share the key word with the purpose byte, so a term
75/// can be applied at most this many times.
76pub(crate) const MAXIMUM_APPLICATIONS: u32 = 1 << 24;
77
78/// How large a noise term's draws are.
79#[derive(Debug, Clone, Copy, PartialEq)]
80pub(crate) enum NoiseLevel {
81    /// `simplenoise`: σ of each real and imaginary draw, Jy, held as CASA
82    /// holds it.
83    Simple(f32),
84    /// `tsys-manual`: σ of each row from the model ([`tsys`]).
85    TsysManual(TsysManual),
86}
87
88/// One application of a noise term: the noise one `corrupt` adds for one
89/// `setnoise` term.
90#[derive(Debug, Clone, Copy, PartialEq)]
91pub(crate) struct NoiseApplication {
92    /// The seed in force when the term was set (`sm.setseed`).
93    pub(crate) seed: i32,
94    /// How large its draws are.
95    pub(crate) level: NoiseLevel,
96    /// How many times the term had been applied before; below
97    /// [`MAXIMUM_APPLICATIONS`].
98    pub(crate) ordinal: u32,
99}
100
101impl NoiseApplication {
102    /// The stream key: the seed's 32 bits (two's complement), then the
103    /// thermal-noise purpose byte above the ordinal.
104    fn key(&self) -> [u32; 2] {
105        debug_assert!(self.ordinal < MAXIMUM_APPLICATIONS);
106        [
107            self.seed as u32,
108            (PURPOSE_THERMAL_NOISE << 24) | self.ordinal,
109        ]
110    }
111
112    /// This application's noise when every row has the same σ
113    /// (`simplenoise`): σ under [`Self::key`]; `None` when σ depends on the
114    /// row (`tsys-manual`).
115    pub(crate) fn uniform(&self) -> Option<CellNoise> {
116        match self.level {
117            NoiseLevel::Simple(sigma_jy) => Some(CellNoise::new(self.key(), sigma_jy)),
118            NoiseLevel::TsysManual(_) => None,
119        }
120    }
121
122    /// Whether σ depends on the row (`tsys-manual`), which then needs each
123    /// row's [`RowNoise`].
124    pub(crate) fn varies_by_row(&self) -> bool {
125        matches!(self.level, NoiseLevel::TsysManual(_))
126    }
127
128    /// This application for the rows of a scan in spectral window `window`.
129    pub(crate) fn for_window(&self, window: &WindowNoise) -> ScanNoise {
130        ScanNoise {
131            key: self.key(),
132            level: match &self.level {
133                NoiseLevel::Simple(sigma_jy) => ScanLevel::Simple(*sigma_jy),
134                NoiseLevel::TsysManual(model) => ScanLevel::TsysManual(model.for_window(window)),
135            },
136        }
137    }
138}
139
140/// A noise application for the rows of one spectral window.
141#[derive(Debug, Clone, Copy, PartialEq)]
142pub(crate) struct ScanNoise {
143    key: [u32; 2],
144    level: ScanLevel,
145}
146
147#[derive(Debug, Clone, Copy, PartialEq)]
148enum ScanLevel {
149    Simple(f32),
150    TsysManual(tsys::WindowTsys),
151}
152
153impl ScanNoise {
154    /// σ of each real and imaginary draw of a row of `row`'s antennas,
155    /// airmasses and integration time, Jy.
156    pub(crate) fn sigma(&self, row: &RowNoise) -> f32 {
157        match &self.level {
158            ScanLevel::Simple(sigma_jy) => *sigma_jy,
159            ScanLevel::TsysManual(model) => model.sigma(row),
160        }
161    }
162
163    /// Add this application's noise to the cell of MAIN row `row`, whose
164    /// antennas, airmasses and integration time are `inputs`:
165    /// `correlations × channels` samples, correlation fastest. An
166    /// autocorrelation row gets real draws only; samples past the last
167    /// whole channel are left alone ([`CellNoise::add_to_row`]).
168    pub(crate) fn add_to_row(
169        &self,
170        (row, inputs): (u64, &RowNoise),
171        autocorrelation: bool,
172        correlations: usize,
173        cell: &mut [Complex32],
174    ) {
175        CellNoise::new(self.key, self.sigma(inputs)).add_to_row(
176            row,
177            autocorrelation,
178            correlations,
179            cell,
180        );
181    }
182}
