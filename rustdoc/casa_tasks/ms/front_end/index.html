The MeasurementSet task binaries on the shared task front end (#931).

Each binary’s main builds a TaskFrontEnd from its provider contract and a callback that reads the resolved run into its typed request; these are the reads and the reply the binaries share. The front end owns the command line, --json-run, Last and logging.
