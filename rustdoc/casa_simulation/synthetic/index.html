Module synthetic 

Source
Expand description

Developer MeasurementSet fixtures generated by the current crate::Simulator. The typed sky/array inputs are shared by imaging/storage tests and the synthetic-ms staging tool. Prediction, corruptions and MS writing have one owner: the native simulator session.
