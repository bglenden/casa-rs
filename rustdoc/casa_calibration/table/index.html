Constants§

LOOKUP_KEPT_ROW_BYTES
Heap a loaded lookup keeps per row: the solution’s grid, its place in the table’s series, and in the series across fields. Measured at about 320 bytes with the loading figure, with a quarter more.
LOOKUP_LOADING_ROW_BYTES
Heap loading a complex table holds per row at most: the row as casa-tables reads the table, and the solution it becomes. Measured at about 3,300 bytes (the #893 review’s 9,996-row probe, and the setapply law in casa-simulation’s session_memory/apply.rs), with a quarter more for the allocator.
SIMULATED_TABLE_ROW_BYTES
Heap a simulated table holds for each row while it is built in memory and saved: the row’s record (twelve named cells, four of them arrays) and its share of the columns the save forms. Measured at about 2,050 bytes (the #891 review’s 36,000-row probe, and the table law in casa-simulation’s session_memory/jones.rs); a quarter more is kept for the allocator.
SIMULATED_TABLE_VALUE_BYTES
Heap a simulated table holds for each value of a row’s CPARAM beyond SIMULATED_TABLE_ROW_BYTES: the value in CPARAM, PARAMERR, FLAG and SNR (17 bytes). Measured at about 16.6 bytes (1.2 million values of a Tf Jones table of 1,024 channels, casa-simulation’s session_memory/troposphere.rs law, which 16 fails); a quarter more is kept for the allocator.
