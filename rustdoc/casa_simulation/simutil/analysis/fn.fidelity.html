pub fn fidelity(
    convolved: &Path,
    out_flat: &Path,
    image_root: &Path,
) -> Result<Fidelity, AnalysisError>
Expand description

simanalyze’s analysis of image_root.image against the sky model: with convolved the convimage output and out_flat the image’s flat, write

  • <image_root>.diff, convolved − out_flat, labelled Jy/beam;
  • <image_root>.fidelity, |convolved| / max(|diff|, d/√2), where d is the difference’s median absolute deviation;

and return d and the scalar fidelity. Both images take the convolved model’s coordinates and beam, and are masked where either input is, as CASA’s image expressions are. The arithmetic is in single precision, as those expressions compute on single-precision images.

Two departures (docs/CASA (C++) bugs.md):

  • CASA writes d/√2 into its expression with %f, rounding it to six decimal places; casa-rs uses the value itself.
  • CASA’s fidelity carries the convolved model’s unit, Jy/beam, which its image expression copies; it is a ratio, and casa-rs gives it no unit.

§Errors

Inputs of different shapes, or a failure to read or write an image or to compute the statistics.
