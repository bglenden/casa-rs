Expand description

Common image metadata behavior shared by persistent and temporary images.

Required Methods§

Source

fn as_any(&self) -> Option<&dyn Any>

Returns this image as Any for crate-level downcasting when the concrete type is 'static.

The compiled image-expression runtime uses this to recognize concrete, 'static source types such as PagedImage<T>. Borrowed view-like sources that are not 'static still fall back to snapshot compilation.

Source

fn coordinates(&self) -> &CoordinateSystem

Borrows the image’s pixel-to-world transform, including axis units and reference frames.

Source

fn units(&self) -> &str

Returns the brightness unit, for example Jy/beam. An empty string denotes unspecified units.

Source

fn misc_info(&self) -> RecordValue

Returns an owned copy of auxiliary metadata.

Source

fn image_info(&self) -> Result<ImageInfo, ImageError>

Reads the image type and restoring beams. Malformed metadata or an unreadable backing store may return an image error.

Source

fn name(&self) -> Option<&Path>

Returns the persistent image path or source name, when the image has one.

fn default_mask(&self) -> Result<Option<ArrayD<bool>>, ImageError>

Returns the default pixel mask, if one is configured.

Used by LEL mask(image) and replace(image, val). The default returns Ok(None) (no mask); concrete image types override this when they store pixel masks.

Returns a named mask slice, mirroring casacore getMaskSlice.

The default implementation slices the fully materialized named mask. Persistent images should override this to route through paged storage.
