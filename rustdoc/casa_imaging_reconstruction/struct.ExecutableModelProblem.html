Struct ExecutableModelProblem 

Source 
pub struct ExecutableModelProblem { /* private fields */ }
Expand description

Reconstruction-branded Compiled Problem accepted by execution and receipts.

Direct inputs are admitted only when no reprojected preparation claim is present. Reprojected inputs can be constructed only by consuming PreparedReprojectedSeed::bind_compiled_problem.

The brand cannot be minted by downstream callers:

ⓘ
use casa_imaging_model::CompiledProblem;
use casa_imaging_reconstruction::ExecutableModelProblem;

fn forge(problem: CompiledProblem) -> ExecutableModelProblem {
    ExecutableModelProblem {
        problem,
        prepared: None,
    }
}
