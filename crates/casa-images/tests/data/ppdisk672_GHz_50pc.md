The unmodified 270 KiB `ppdisk672_GHz_50pc.fits` is the public Wolf & D'Angelo
(2005) model used by the CASA ALMA protoplanetary disk tutorial, revision 41893:
<https://casaguides.nrao.edu/index.php?title=Protoplanetary_Disk_Simulation_CASA_6.6.6&oldid=41893>.
Downloaded from
<https://bulk.cv.nrao.edu/almadata/public/casaguides/sim_inputs/ppdisk672_GHz_50pc.fits>.
CASA 6.7.6.14 independently supplies the metadata expectations in
`legacy_simulation_fits.rs`. The full 147,000-row tutorial is an opt-in evidence
run; the default regression only imports this small input.
