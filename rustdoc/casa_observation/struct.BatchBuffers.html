Struct BatchBuffers 

Source 
pub struct BatchBuffers { /* private fields */ }
Expand description

The storage behind one VisibilityBatch.

Owned by the caller (or a BufferPool), filled in place by a cursor and lent to the batch. Its arrays are private: a cursor fills them through Self::begin, which checks the batch’s BatchHeader against the observation’s Catalogue and reserves exactly the arrays it describes, and BatchFill::finish checks the filled arrays once; the buffers then keep the header and a shared reference to that catalogue. The batch is built from the header, the arrays and the catalogue’s partition entry and nothing else, so no second description of the same data can drift from the arrays: the per-partition constants (frequencies, correlations, baselines, time system, data group) are never copied into a batch, and no other catalogue can be paired with the arrays.

Clearing keeps capacity, so after the first fill of the largest batch a traversal allocates nothing. Buffers made Self::with_envelope never hold more than their envelope, whatever sequence of batch shapes and roles they are filled with. The buffers are Send: they can be handed between work units whole, which is how a batch’s lifetime is separated from a traversal’s.

pub fn begin( &mut self, header: BatchHeader, catalogue: &Arc<Catalogue>, ) -> Result<BatchFill<'_>, ObservationError>

Start filling a batch described by header, for an observation with catalogue: the header is checked against the catalogue (the partition, data group, channel window and correlation axis exist), and the arrays are cleared and reserved to exactly the batch’s lengths, then lent through the returned fill.

§Errors

ObservationError::InvalidBatch when the header does not fit the catalogue; ObservationError::InvalidRequest when the batch needs more than the buffers’ envelope. Nothing has been allocated, and the buffers hold no batch.

impl BatchBuffers

Source

pub fn pack( &mut self, batch: &VisibilityBatch<'_>, ) -> Result<usize, ObservationError>

Copy batch (typically a compute window of a larger batch) into these buffers, replacing what they held, through the same checked fill a cursor uses, and return the payload elements copied: the explicit, accounted packing that gives a window storage of its own. Strided views are gathered into standard order; a weight shared by every channel stays one per correlation; shared quantities keep their sharing; the piece refers to the batch’s catalogue.

§Errors

When the batch’s data group is not in the catalogue’s partition, or the piece needs more than the buffers’ envelope.
