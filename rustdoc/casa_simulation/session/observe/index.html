sm.settimes, sm.observe and sm.observemany: the schedule of scans.

observe records a scan, and observemany a run of pointings, each pointing a scan of its own; the session writes every scan’s rows at close. The bookkeeping follows NewMSSimulator::observe, whose one-source form is observemany with one pointing and no direction:

  • scan numbers continue from the last scan, and a run of pointings of one field shares one;
  • an OBSERVATION row is added when asked for or when there is none;
  • STATE rows are shared by identical states;
  • each pointing’s integration count is max(1, Int(0.5 + (stop − start)/Tint)).

Times honour the requested UTC (plan decision 5). CASA adds the reference time in TAI to start and stop and stores the result in a TIME column labelled UTC, so its rows are TAI − UTC (37 s) late. casa-rs adds the reference time in UTC.
