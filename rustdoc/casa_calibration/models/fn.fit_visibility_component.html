Expand description

Fit one component to the selected visibilities of an open MeasurementSet.

The fit reads CORRECTED_DATA and leaves the selected data unchanged. A negative iteration limit returns the initial component without reading samples.

§Errors

Returns an error on unreadable data, multiple selected fields, invalid component parameters or a selection with no data of positive weight.
