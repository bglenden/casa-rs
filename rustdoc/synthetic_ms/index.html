synthetic-ms: the synthetic MeasurementSet generator as a developer tool (simulation Phase 5d, #841).

It runs one request of the generator in casa_ms::simulation, unchanged, from JSON:

synthetic-ms --json-run <request.json | ->

The request is {"kind": "run", "request": ...} (a casa_ms::simulation_task::SimobserveRunTaskRequest) or {"kind": "family", "request": ...} (a SimobserveFamilyTaskRequest), and the result envelope is printed as simobserve --json-run printed it. The benchmark and dataset tools under tools/perf/imager call it, so their datasets stay as they were when simobserve becomes CASA’s task (Phase 5c). It is not a catalog task and is not installed with the suite.
