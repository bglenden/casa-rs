Crate flagdata 

Source
Expand description

flagdata - native CASA-style MeasurementSet flagging, on the shared task front end. It takes CASA 6.7.6’s values and returns what CASA’s task returns (#931): the summary dictionary in summary mode, {} otherwise. The CASA values it does not implement yet are refused naming #978.
