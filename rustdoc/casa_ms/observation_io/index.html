Storage adapters behind the shared observation contracts (casa-observation): MeasurementSet v2 here, MSv4 with the msv4 feature.

open is the one place a store’s format is chosen: it returns the shared [Observation] interface, behind which each adapter dispatches once per bind and once per batch. Algorithm code takes that interface and imports neither concrete adapter.

Trial status. These adapters implement the cases the MSv2/MSv4 trial’s examples need (docs/measurement-set/trial/README.md), at the trial’s second revision (revision-2-design.md): the MSv2 adapter grids rows onto time × baseline at opening and partitions them as XRADIO’s converter does, so both adapters deliver the same batches. The production readers and writers are unchanged.

persisted_namespace
The namespace of the store at source as super::open opens it with options, which decide its partitions: an MSv2’s own subtables, its catalogue’s antennas, fields and sessions being their rows and each partition naming its data description’s spectral window; or for an MSv4 the subtables its MSv2 conversion would hold, in catalogue order.
