Convert the store at source (MSv2 or MSv4) into a new MSv4 processing set at destination.

Every partition becomes one dataset with the selected data groups (ConversionOptions::data_groups) and the antennas its baselines name (others are Loss::UnusedAntennas). An MSv4’s datasets keep their names. An MSv2’s are named as XRADIO’s converter names them: the file name without .ms, then the partition’s number in the order the partitions’ first MAIN rows appear, padded with zeros to the width of the largest. Its antennas (for the telescopes XRADIO renames, by the first observation’s telescope), fields, sources and spectral windows are renamed as that converter renames them (NAME_STATION, NAME_FIELD_ID, NAME_SOURCE_ID, NAME_SPECTRAL_WINDOW_ID), so the two converters’ stores agree; a source XRADIO finds no row for in one spectral window, which it names Unknown there, is still named here. Two partitions XRADIO would merge, rows of different feeds, are two datasets here, and rows with STATE_ID -1 have no intents here where XRADIO gives them the last STATE row’s; the datasets numbered after such a difference can hold other data than XRADIO’s of the same name. A dataset whose fields follow an ephemeris holds it as XRADIO’s field_and_source_ephemeris, the samples on time_ephemeris from the last before its first time to the first two minutes past its last (the samples no dataset holds are a reported loss), with the phase centre at each time as XRADIO states it. Partitions are converted ConversionOptions::workers at a time; nothing appears at destination until every dataset is complete.

§Errors

All before anything is written: ObservationError::InvalidRequest naming the first loss not accepted, or an ephemeris that does not cover a dataset’s times; ObservationError::Unsupported for fields whose direction is a polynomial in time, a dataset whose fields follow different ephemerides (or only some one), or radial velocities that are not geocentric. Otherwise, any error opening or reading the source or writing the destination, which then is not created.
