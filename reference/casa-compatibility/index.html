    casa-rs and CASA 6.7.6.14 tasks¶

    Truth class: generated reference Generated by: scripts/check-casa-inventory.py --write Sources: resources/casa-compat/casa-6.7.6.14/ (read from CASA by tools/casa-compat/dump_casa_task_inventory.py), crates/casa-provider-contracts/resources/parameter-surfaces.json

    Do not edit this file by hand. Regenerate it after changing the inventory or a surface.

    Each casa-rs task that mimics a CASA task (#931) against that task as CASA 6.7.6.14 defines it: whether it presents CASA's signature, the CASA parameters casa-rs does not take yet, those it takes but accepts only at CASA's default, the parameters casa-rs takes that CASA does not (casa-rs names for CASA concepts, or casa-rs-only controls), whether the shared parameters keep CASA's order, and the defaults that differ. calibrate and msexplore are casa-rs tasks with no CASA counterpart.

    The CASA parameters casa-rs lacks or accepts only at their defaults are tracked by family: images in #977, MeasurementSet and flagging in #978, calibration in #979 and tclean in #980.
