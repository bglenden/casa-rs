Expand description

One array of a normal state’s scalars, written and read only by the normal state that allocated it.

Complex values are stored as consecutive real/imaginary f64 values. Access must not enlarge an admitted cache. The owner writes every logical value before transferring the generation; storage handles must not permit mutation through aliases retained outside this capability. The trait is the dependency boundary for casa-imaging-runtime’s paged storage, the second implementation beside the resident Box<[f64]>.

fn read( &self, start: usize, len: usize, ) -> Result<Cow<'_, [f64]>, NormalStateError>

Return exactly len scalars. Resident windows borrow their backing and retained memory permit; paged windows own the bounded decoded allocation. Owned windows used as complex pairs must also have an even capacity so their allocation can transfer without repacking; invalid layouts fail.

fn retained_resident_bytes(&self) -> usize

Actual live heap payload held under a retained runtime memory permit. Excludes unused reservation capacity, metadata and paged caches. Backings without that allocation/permit guarantee conservatively report zero.

fn read_real( &self, _start: usize, _values: usize, ) -> Result<Option<Cow<'_, [f32]>>, NormalStateError>

Borrow or load a real Float image directly when the backing stores one. Other normal families keep their existing complex access path.

fn write_real( &mut self, start: usize, values: &[f32], ) -> Result<(), NormalStateError>

Write a real Float image window at complex-scalar offsets. Other normal implementations may widen through their scalar interface; the managed cube backing writes Float planes directly.
