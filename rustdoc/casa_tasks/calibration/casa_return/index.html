Module casa_return 

Source
Expand description

What CASA 6.7.6.14’s calibration tasks return (#931), built from casa-rs’s reports. tools/casa-compat/record_casa_returns.py records the structure of CASA’s own returns, which the task tests compare these with.

  • gaincal and bandpass return the tables they applied and solved, the data they selected and how far their solution intervals got (solvestats, SolveStats).
  • fluxscale returns its flux densities per field and spectral window, with the fit across windows.
  • applycal and gencal return None.
