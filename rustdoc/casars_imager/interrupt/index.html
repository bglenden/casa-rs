Module interrupt 

Source
Expand description

SIGINT cancels the run (plan section 5.4). The first interrupt sets the process’s cancellation token: the run stops at the next block boundary of a pass or before its next phase, and publishes nothing. A system call the interrupt lands in is restarted, so a read in flight completes rather than failing with EINTR. The handler then resets itself, so a second interrupt terminates the process.
