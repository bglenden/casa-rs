Struct BlockPredictor 

Source 
pub struct BlockPredictor<'w> { /* private fields */ }
Expand description

Predicts blocks of native rows, Σ_d A_d·m_d over its image domains (SIMapperCollection::degrid), for a caller that is not a major cycle: the simulator, which predicts the rows it writes. It is the major-cycle pass’s own prediction (super::MajorCyclePass): each row as SpectralResampler::predict_row predicts it, a flagged row, a flagged sample and an autocorrelation (unless the domain’s resampler is SpectralResampler::predicting_autocorrelations) predicting zero.

The rows are predicted in row chunks on a WorkerTeam, on the CPU or on Metal (BackendChoice). Each chunk keeps one prediction batch and one backend per domain, so a predictor holds Self::bytes whatever blocks within its BlockShape it predicts; on Metal the model at the block’s native cells is formed in device memory and copied out. A domain’s model grids, and on Metal their device copy, are the caller’s to admit (PreparedModelGrids::bytes).

The CPU’s predictions do not depend on the workers, the chunking or how the rows are split into blocks; Metal’s agree with them to the device’s f32 arithmetic.

pub fn bytes( domains: &[PredictionDomain<'_>], backend: BackendChoice, block: BlockShape, workers: usize, ) -> u64

Bytes Self::new holds, and Self::predict_into while it runs, for the same arguments: each chunk’s prediction batch and record, each chunk’s backend per domain with what it keeps (CpuBackend::batch_bytes and its per-sample buffers; on Metal [casa_imaging_metal::ring_bytes], [casa_imaging_metal::batch_bytes] and [casa_imaging_metal::kernel_bytes]), on Metal the model at the largest block’s native cells in device memory, and a call’s hand-off of the chunks to the team. The rows, the model grids and the output are the caller’s.

pub const fn noise_bytes( backend: BackendChoice, block: BlockShape, terms: usize, ) -> u64

Bytes a predictor of blocks of at most block on backend holds beyond Self::bytes once Self::predict_into_with_noise has added noise of at most terms terms: on Metal the one backend that adds it keeps the rows and the terms on the device ([casa_imaging_metal::noise_bytes]); nothing on the CPU, where the predictor adds none. The DeviceNoise is the caller’s.

pub fn new( domains: &[PredictionDomain<'w>], backend: BackendChoice, block: BlockShape, workers: usize, stage_timing: bool, ) -> Result<Self, PassError>

A predictor of blocks of at most block (rows, channels and correlations; each row projected on every domain) over domains on backend, in the chunks of workers workers; with stage_timing, each Metal backend logs its usage when it drops ([casa_imaging_metal::METAL_STAGE_TIMING]).

§Errors

PassError::NoDomains without a domain, PassError::Workers for no workers, and on Metal PassError::Operator when the host has no device.

§Panics

On Metal, when an operator is not f32: the device grids are f32.

pub fn predict_into( &mut self, block: &NativeBlock, team: &WorkerTeam, out: &mut [Complex32], ) -> Result<(), PassError>

The model visibility of every selected sample of block’s rows, summed over the domains, into out as [row][channel][correlation] in the block’s row order, on team. Every value of out is written.

§Errors

A row the operators reject (PassError::Operator), or a device failure on Metal.

§Panics

When block exceeds the predictor’s BlockShape, does not project each row on every domain, or out is not one value per sample.

pub fn adds_noise_on_device(&self) -> bool

Whether the predictor forms the model in device memory, where Self::predict_into_with_noise adds noise to it.

pub fn predict_into_with_noise( &mut self, block: &NativeBlock, team: &WorkerTeam, out: &mut [Complex32], noise: DeviceNoise<'_>, ) -> Result<(), PassError>

Self::predict_into with noise added to every row’s model on the device before it is copied out: the draws of casa_numerics::cell_noise::CellNoise::add_to_row for each term in order, with each row’s number and autocorrelation flag from noise.rows (one per row of block). The simulator corrupts the rows it predicts this way, with no pass of its own over the cells.

§Errors

As Self::predict_into.

§Panics

As Self::predict_into; when the predictor does not Self::adds_noise_on_device, or noise.rows is not one row per row of block.
