The data channels SynthesisParamsImage::buildCoordinateSystemCore keeps for a cube whose start is unset (SynthesisUtilMethods.cc ~line 2986), or None when it keeps them all.

CASA cuts the data channels when band_hz, the selected band (casa_selected_band_hz), begins above their lowest channel centre, so that the default start is the first selected channel. The cut runs from the channel whose centre lies within half its width above the band’s lower edge to the one within half its width below the upper edge, the rest of the channels where none does. As in CASA, one channel cannot bound both ends, and the test reads the signed CHAN_WIDTH, so a window stored with negative widths is never cut.
