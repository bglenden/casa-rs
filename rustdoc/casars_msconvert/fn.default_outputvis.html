pub fn default_outputvis(vis: &Path, outformat: StoreFormat) -> Option<PathBuf>
Expand description

The output a conversion of vis into outformat writes when none is named, by XRADIO’s convention: beside vis, named after it, its extension (.ms, .zarr or .ps.zarr, any case) replaced by .ps.zarr for a processing set or .ms for a MeasurementSet v2 (StoreFormat::extension), or that extension added to a name without one: obs.ms becomes obs.ps.zarr, and obs.ps.zarr obs.ms. None when vis names no file, or a name that is not UTF-8.
