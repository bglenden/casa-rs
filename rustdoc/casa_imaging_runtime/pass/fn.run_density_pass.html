Expand description

Accumulate the weight-density grid of shape over one traversal of the first image domain’s projection: each row is placed with SpectralResampler::place_density on row chunks and the chunks are added in row order. It holds density_pass_bytes while it runs.

The traversal reads flags and weights only (SampleContent::FlagsAndWeights): a density placement carries the sample’s weight and no value.
