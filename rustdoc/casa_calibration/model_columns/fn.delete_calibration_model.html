Expand description

Delete selected virtual models and/or the entire scratch model column.

CASA resolves field and spw when virtual_model is true. An empty field selection clears every virtual model. The scratch deletion includes any physical backing columns used for compression.

§Errors

Returns an error for an invalid selector or a failed table update.
