calibrate, the calibration task provider, on the shared task front end (#931).

One binary hosts the general calibrate surface, whose mode picks the workflow, and the CASA-named applycal, gaincal, bandpass, fluxscale and gencal, one workflow each. The command line’s first word names the surface (calibrate gaincal --ms ...); calibrate runs otherwise. The front end owns the command line, --json-run, Last and logging; this module reads the resolved run into its CalibrationTaskRequest, runs it, and writes its report.

A run’s reply carries the tagged CalibrationTaskResult and the value CASA’s task returns: gaincal and bandpass their tables, selected data and interval counts (solve_record), fluxscale its flux densities (fluxscale_record), and applycal, gencal and calibrate None. A command line prints the workflow’s report in format, or writes it to output; a report that would replace an existing file is refused before the task runs unless overwrite is set.
