pub fn check_fields(
    catalogue: &Catalogue,
    grid: &TimeBaselineGrid,
    times_s: &[f64],
    frame: DirectionRef,
) -> Result<(), ObservationError>
Expand description

Refuse what write_fields cannot write of the fields grid’s times name (at times_s, Unix seconds) for data whose UVW is in frame, so that a conversion refuses it before anything is written.

§Errors

ObservationError::Unsupported for a phase centre in another frame than frame, fields of which only some follow an ephemeris or that follow different ones (XRADIO’s dataset holds one), or an ephemeris whose radial velocities are not geocentric; ObservationError::InvalidRequest for an ephemeris that does not cover the times.
