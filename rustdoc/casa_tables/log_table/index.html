CASA-compatible logging sinks and tracing integration.

The instrumentation facade for workspace code is [tracing]. This module owns the CASA-specific priority model, log-table serialization, and sink / layer building blocks. CLI flag/environment configuration and global subscriber initialization belong to casars-cli.

An event’s fields follow its message as name=value, separated by spaces: a string value containing whitespace, or an empty one, is written as a quoted Rust string literal, a ? value as its Debug form (quoted for strings) and a % value as its Display form.
