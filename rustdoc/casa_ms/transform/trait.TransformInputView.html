Expand description

A bounded, read-only source for columns computed from the input MeasurementSet, for example calibrated visibilities.

Array shapes are the physical input shapes. The transform applies correlation and channel selection after reading them. An implementation returns one cell per requested physical row in request order and may leave untouched column names to the ordinary table reader.
