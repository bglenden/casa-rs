Struct GroupCompletion 

Source 
pub struct GroupCompletion { /* private fields */ }
Expand description

Joins the two completions of a group that concurrent work consumes: its input (a closing fragment or ReadEvent::GroupEnd) and the work units begun on its fragments or windows. A group is ready to finalize only when both have happened.

A consumer calls Self::begin for each unit of work it starts on a group, which hands out a WorkToken; gives the token to Self::finish when that unit is done; and calls Self::close when the source completes the group’s input. Whichever call makes the group ready returns true, once. Tokens cannot be copied, so a unit finishes once and only begun work can finish.

A token dropped unfinished (its unit panicked, failed or was cancelled) abandons its group: the group never becomes ready, and the next Self::finish, Self::close or Self::is_idle reports ObservationError::WorkAbandoned rather than waiting for work that will not come.

One completion serves one traversal. A source completes the input of a (partition, field, scan) series’ groups in bin order, since it delivers whole times in time order, so the completion keeps only each series’ latest closed bin to refuse a second closure or work begun after one: its memory is the series and the groups in flight, however long the traversal.
