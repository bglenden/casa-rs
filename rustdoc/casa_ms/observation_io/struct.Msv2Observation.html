Struct Msv2Observation

Expand description

An opened MeasurementSet v2 and its catalogue.

Opening reads MAIN’s key columns in row chunks and partitions the rows the way XRADIO’s converter does (DATA_DESC_ID × OBS_MODE × OBSERVATION_ID × EPHEMERIS_ID and the opening’s PartitionScheme), and further by the feed pair, which XRADIO does not split by. A row whose STATE_ID is -1 has no intents here, where XRADIO’s converter gives it the last STATE row’s OBS_MODE (NumPy’s index -1), so an MS mixing such rows with STATE rows partitions differently. Each partition’s rows are placed on its time × baseline grid (the index module). Each partition has one data group, base, associating DATA, FLAG, WEIGHT_SPECTRUM (when its first row has content, else WEIGHT) and UVW. Antenna, field and observation identities are the subtable rows; scans are the distinct SCAN_NUMBERs in ascending order.

Opening checks every unit and measure reference the batches rely on: TIME and TIME_CENTROID share one fixed reference (a variable reference is refused); the UVW convention is resolved to the phase centres’ frame (UvwFrame); positions, diameters, angles and frequencies are in the units their types claim.

pub fn open(path: impl AsRef<Path>) -> Result<Self, ObservationError>

Open the MeasurementSet at path and read its catalogue.

The tables stay open with casacore read locks, and their payload rows stay on disk: the typed column fills read only the selected cells, as the production selected-observation source does.

§Errors

When the MeasurementSet cannot be opened, a subtable the catalogue needs is missing or malformed, a unit or measure reference is outside the trial profile, or the rows do not fit their grids (two rows in one cell, two fields or scans at one time, several PROCESSOR_IDs in one partition).

pub fn open_granted( path: impl AsRef<Path>, options: &OpenOptions, grant: &mut dyn FnMut(usize) -> Result<(), ObservationError>, ) -> Result<Self, ObservationError>

Self::open_with, asking grant for the bytes the opening will hold before it allocates them: its tables’ descriptions and keywords (bounded by their files), the rows of the subtables its catalogue is read from (a table loads every row on first touch and keeps them) and what is read from them, then its index (its chunk of MAIN’s key columns, each partition’s distinct times, baselines and processors as the first pass finds them, at most one row’s beyond what was granted, then the scans and the grids) and its partitions’ entries. The totals asked for only grow, a few at a time; a caller that admits memory admits each increase. An error from grant refuses the opening with nothing more allocated. Temporary payload staging in the spectral-weight content probes is not yet separately charged; issue #1041 tracks that inherited gap.

§Errors

As Self::open, and whatever grant returns.

pub fn open_granted_on( ms: MeasurementSet, options: &OpenOptions, grant: &mut dyn FnMut(usize) -> Result<(), ObservationError>, ) -> Result<Self, ObservationError>

Self::open_granted on ms, a MeasurementSet already open for a retained read (MeasurementSet::open_retained_read), so that a caller who reads MAIN’s row count to admit the opening opens it once. The caller must admit Self::opening_table_bytes before opening ms; this method includes those bytes in each subsequent grant.

pub fn row_flagged( &self, id: PartitionId, time_s: f64, baseline: OrderedBaseline, ) -> Result<Option<bool>, ObservationError>

Whether the MAIN row partition id holds at time_s on baseline (Self::main_row) is row-flagged (FLAG_ROW); None where no row fills the cell. The batches fold FLAG_ROW into every value’s flag, as an MSv4 holds no row flags; this states the row flag itself, for a consumer that follows CASA’s use of it, such as AW projection’s reference time (CASA getPA), where a row whose flags are all set but whose FLAG_ROW is not still counts.

§Errors

When MAIN’s FLAG_ROW cannot be read.

§Panics

If id is not a partition of the observation.

pub fn feed_receptors( &self, antenna: AntennaId, feed: i32, window: WindowId, ) -> Option<&Receptors>

Antenna antenna’s receptors through feed feed in spectral window window, as casacore’s MSIter::setFeedInfo gives them to its iterator (receptorAngles; the last row where FEED varies in time), whatever feeds MAIN’s rows name; None without a row. CASA’s AW projection reads feed 0’s (feed_pa: receptorAngles().xyPlane(0)), where a partition’s receptors are those of the feeds its rows name.
