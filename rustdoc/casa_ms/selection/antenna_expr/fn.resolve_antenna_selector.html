pub fn resolve_antenna_selector(
    antennas: &[AntennaRow<'_>],
    text: &str,
) -> MsResult<BaselineSelection>
Expand description

Resolve CASA antenna selection text against antennas, the ANTENNA table’s rows in row order.

The empty string is no constraint, as MSSelection skips an empty antenna expression. See the module documentation for the expression forms and how each selects baselines.

§Errors

MsError::InvalidInput, worded as CASA’s MSSelectionAntennaParseError, when the text does not scan or parse, when any name, pattern, regex, station or ID in it matches no antenna, when a length unit is unknown or not a distance, or when a regex does not compile or uses an ECMAScript feature the port lacks.
