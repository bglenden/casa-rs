Expand description

A configuration file that cannot be read. Where CASA reports the same failure, the message is CASA’s.

Variants§

§

Io

The file could not be read.

Fields

§path: PathBuf

The file.

§source: Error

The I/O error.

§

InvalidNumber

An antenna column that should be a number is not one.

Fields

§path: Option<PathBuf>

The file, when the configuration was read from one.

§line: usize

The 1-based line number.

§value: String

The column’s text.

§

MissingCoordinateSystem

The header has no coordsys.

§

UnknownCoordinateSystem

coordsys is none of XYZ, UTM, LOC….

Fields

§value: String

The coordsys value.

§

LocalNeedsObservatory

Local coordinates with neither a known observatory nor COFA.

§

MissingZone

UTM without zone.

§

InvalidZone

A zone that is not an integer.

Fields

§value: String

The zone value.

§

MissingDatum

UTM without datum.

§

UnknownDatum

A datum code that is not in geodesy::DATUMS.

Fields

§code: String

The datum value.

§

MissingHemisphere

UTM without hemisphere, or with an empty one.

§

InvalidCofa

A COFA that is not longitude,latitude.

Fields

§value: String

The COFA value.

§

NoAntennas

An unknown observatory with no antennas to place it by.

§

Measures

The telescope name.
