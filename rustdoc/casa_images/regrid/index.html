Module regrid 

Source
Expand description

Regridding an image’s direction axes onto another grid, as casacore’s ImageRegrid regrids them for imregrid and the image tool’s regrid.

The output grid is a RegridTemplate: a coordinate system and a shape, what imregrid(template='get') returns and what simanalyze and simutil.convimage build from one image to regrid another onto. Each output pixel of the direction axes is converted to world coordinates on the template and back to an input pixel, and the input plane is sampled there by casacore’s Interpolate2D rules (RegridMethod):

  • nearest: the nearest pixel within half a pixel (0.5001) of the image;
  • linear: the 2 × 2 pixels from the position truncated toward zero, moved back by one at the far edge, so positions from −1 to the last pixel plus one are accepted and up to a pixel past an edge is extrapolated;
  • cubic: Numerical Recipes’ bicubic (bcucof) from finite-difference derivatives on the 4 × 4 pixels around the position, falling back to linear within a pixel of an edge.

A pixel that cannot be sampled, because its position is off the image or a pixel it needs is masked, is 0 and masked, as regrid2DMatrix leaves it. A Jy/pixel image is scaled by the ratio of the output to the input pixel area (ImageRegrid::findScaleFactor), so the flux is kept.

casacore converts the positions on a coarser grid when decimate is above 1 (10 by default): every floor(n / (floor(n / decimate) − 1))-th output pixel, interpolating between them (make2DCoordinateGrid). casa-rs converts every output pixel, as casacore does with decimate=0, so its positions are exact.

Only the direction axes are regridded, in the same frame. For every other coordinate:

  • where all its axes have one pixel in both images, casacore does not regrid it and the output keeps the input’s coordinate (CASA 6.7.6 keeps the input’s channel and Stokes for a template at another frequency or Stokes), and so does casa-rs;
  • otherwise the template’s must be the input’s: the same type, names, units, spectral frame and rest frequency or Stokes list, and the same world value at every pixel. A different one is refused rather than relabelled.
