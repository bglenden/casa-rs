Module ephemeris_table 

Source
Expand description

CASA ephemeris tables for tests: the layout casacore’s MeasComet reads (an IERS table of regularly spaced samples with its MJD0, dMJD and VS_* keywords) and XRADIO’s converter reads (GeoLong, GeoLat, GeoDist, obsloc, posrefsys, the columns’ UNIT), both as a MeasurementSet field’s attached ephemeris (FIELD/EPHEM<id>_<name>.tab) and as a phasecenter table.
