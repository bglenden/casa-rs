The command-line and task surface of casa-rs’s simulation tasks: simobserve (simulation Phase 5c, #841), with simanalyze and simalma to come, on the shared task front end (#931).

As for the imager, the front end resolves the parameters through the provider-contracts catalog: command-line flags and a --json-run request become the same resolved values, CASA’s parameters with CASA’s defaults, and those values, and nothing else, make the [SimobserveRequest] the task runs. The host adds what CASA’s task takes from its environment: CASA’s data directories, where alma/simmos holds the antenna configurations, and the measures data. A run’s reply carries its SimobserveRunTaskResult; simobserve returns None, as CASA’s does.
