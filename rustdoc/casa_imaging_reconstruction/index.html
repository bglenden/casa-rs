Crate casa_imaging_reconstruction 

Source
Expand description

Authoritative solver-independent model-state lifecycle.

The model crate supplies only closed commitments and value schemas. This crate owns the model, its updates and the major cycle that pairs it with the normal state, without importing storage, execution, product, or solver APIs.
