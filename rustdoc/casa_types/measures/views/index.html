casa_types::measures

Module views 

Source
Expand description

Borrowed array views of measures: many values sharing one reference.

A scalar measure such as MEpoch or MFrequency carries its own reference. Observation data hold thousands of values that share one, so these views pair a borrowed ndarray view of the numbers with the reference and unit they share, stated once. They are the same Measures vocabulary as the scalar types, not an observation-specific copy of it: EpochView::get, FrequencyView::get and UvwView::get give the scalar measure of one element on the stack, and the references are the scalar types’ own EpochRef, FrequencyRef and DirectionRef.

The unit of each view is fixed by its type: frequencies are hertz, epoch offsets and durations seconds, UVW metres. A consumer that needs those units reads them without inspecting a unit string; a source holding other units scales them when it fills the view, never after.

These views are the first part of the bulk Measures interface the MSv2/MSv4 trial needs (docs/measurement-set/contracts.md, “Shared Measures types and bulk conversion”); prepared bulk conversions over them are later work.

§Examples

use casa_types::measures::frequency::FrequencyRef;
use casa_types::measures::{EpochRef, EpochView, FrequencyView, MjdHighPrec};
use ndarray::array;

// MeasurementSet v2 TIME: seconds since MJD 0, UTC.
let seconds = array![4_895_231_290.0, 4_895_231_300.0];
let times = EpochView::new(EpochRef::UTC, MjdHighPrec::new(0.0, 0.0), seconds.view());
assert_eq!(times.len(), 2);
assert!((times.get(1).value().as_mjd() - 56_657.769_675_9).abs() < 1e-6);

let hz = array![44.0e9, 44.128e9];
let frequencies = FrequencyView::new(FrequencyRef::LSRK, hz.view());
assert_eq!(frequencies.hz()[1], 44.128e9);
