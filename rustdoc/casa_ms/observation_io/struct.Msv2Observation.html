Struct Msv2Observation

pub struct Msv2Observation { /* private fields */ }
Expand description

An opened MeasurementSet v2 and its catalogue.

Opening reads MAIN’s key columns in row chunks and partitions the rows the way XRADIO’s converter does (DATA_DESC_ID × OBS_MODE × OBSERVATION_ID × EPHEMERIS_ID and the opening’s PartitionScheme), and further by the feed pair, which XRADIO does not split by. A row whose STATE_ID is -1 has no intents here, where XRADIO’s converter gives it the last STATE row’s OBS_MODE (NumPy’s index -1), so an MS mixing such rows with STATE rows partitions differently. Each partition’s rows are placed on its time × baseline grid (the index module). Each partition has one data group, base, associating DATA, FLAG, WEIGHT_SPECTRUM (when MAIN has it, else WEIGHT) and UVW. Antenna, field and observation identities are the subtable rows; scans are the distinct SCAN_NUMBERs in ascending order.

Opening checks every unit and measure reference the batches rely on: TIME and TIME_CENTROID share one fixed reference (a variable reference is refused); the UVW convention is resolved to the phase centres’ frame (UvwFrame); positions, diameters, angles and frequencies are in the units their types claim.

pub fn pointing_bytes(&self) -> Result<usize, ObservationError>

The most bytes a pointing query of this observation holds while it is read and once it is answered, whatever its antennas and times: every POINTING row taken as a candidate at four polynomial terms (the production source’s bound), with one scan block of at most every row, and the series it gives. A [PointingRequest] with this budget is never refused for its size, and reads POINTING in blocks as large as a query may scan. Zero without a POINTING table.

§Errors

When POINTING cannot be read.

pub fn open(path: impl AsRef<Path>) -> Result<Self, ObservationError>

Open the MeasurementSet at path and read its catalogue.

The tables stay open with casacore read locks, and their payload rows stay on disk: the typed column fills read only the selected cells, as the production selected-observation source does.

§Errors

When the MeasurementSet cannot be opened, a subtable the catalogue needs is missing or malformed, a unit or measure reference is outside the trial profile, or the rows do not fit their grids (two rows in one cell, two fields or scans at one time, several PROCESSOR_IDs in one partition).

pub fn open_granted( path: impl AsRef<Path>, options: &OpenOptions, grant: &mut dyn FnMut(usize) -> Result<(), ObservationError>, ) -> Result<Self, ObservationError>

Self::open_with, asking grant for the bytes the opening’s index will hold before it allocates them: its chunk of MAIN’s key columns, each partition’s distinct times, baselines and processors as the first pass finds them (at most one row’s beyond what was granted), then the scans and the grids. The totals asked for only grow, a few at a time; a caller that admits memory admits each increase. An error from grant refuses the opening with nothing more allocated.

§Errors

As Self::open, and whatever grant returns.

pub const fn opening_bytes(main_rows: usize) -> usize

The bytes opening a MeasurementSet of main_rows MAIN rows holds when its grids are full and its times hold a few rows each: a cell and eight bytes of time tables per row, and one chunk of key columns.
