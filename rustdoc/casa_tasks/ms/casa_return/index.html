Module casa_return 

Source
Expand description

What CASA 6.7.6.14’s flagging tasks return (#931), built from casa-rs’s results. tools/casa-compat/record_casa_returns.py records the structure of CASA’s own returns, which the task tests compare these with.

  • flagdata in summary mode returns its summary dictionary; its other modes return an empty dictionary.
  • flagmanager in list mode returns its flag versions keyed 0, 1… with the MeasurementSet’s path under 'MS'; its other modes return None.

flagdata’s summary-mode return: CASA’s dictionary of flagged and total samples, overall and per antenna, array, correlation, field, observation, scan and spectral window, in CASA’s key order.
flagmanager_list_record
flagmanager’s list-mode return: each saved flag version, keyed by its position, as {'name': ..., 'comment': ...}, and the MeasurementSet’s absolute path under 'MS'. The main entry, the working flags, is not a saved version and is left out, as CASA leaves it out.
