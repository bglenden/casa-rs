Struct TiledArrayStorageLayout 

Source 
pub struct TiledArrayStorageLayout { /* private fields */ }
Expand description

Prepared physical layout for one typed tiled array and its standard table metadata.

Preparation performs no filesystem I/O and allocates no pixel payload. The encoded control files are produced by the same serializers as ordinary tables; creation writes those bytes directly without an eager placeholder row. Cache and index capacities are separate from caller-owned slice arrays.
