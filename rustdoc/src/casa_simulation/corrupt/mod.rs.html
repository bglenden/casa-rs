2//! Visibility corruption: thermal noise, CASA's `ANoise` term
3//! (`sm.setnoise(mode='simplenoise')` then `sm.corrupt()`).
4//!
5//! # What CASA adds
6//!
7//! Measured against CASA 6.7.6 (simulation Phase 1d probes, #841), each
8//! `corrupt` adds, for every noise term, to every DATA sample:
9//! - on a cross-correlation row, independent real and imaginary draws, each
10//!   N(0, σ²), where σ is the term's `simplenoise` in Jy;
11//! - on an autocorrelation row, a real draw only: the imaginary part is
12//!   unchanged;
13//! - in every correlation, the cross-hands of four-correlation data
14//!   included, each with its own draw;
15//! - whatever the flags: flagged rows and samples get noise too.
16//!
17//! WEIGHT and SIGMA are left as observed. CASA's `ANoiseCorruptor::simPar`
18//! draws in double precision and rounds `Complex(r·amp, i·amp)`, σ held as
19//! a `Float`, to the single precision DATA is stored in. casa-rs draws in
20//! single precision instead, and scales by σ in it too, for speed: a vector
21//! register holds four lanes rather than two and the series are about half
22//! as long. On an Apple M2 core that nearly halves the noise's cost, from
23//! 6.2 to 3.2 ns per complex sample of two-correlation rows, the generator's
24//! 1.2 ns included (#855). The difference is below what the stored `f32`
25//! resolves: against noise of standard deviation σ it is of order 10⁻⁷σ
26//! ([`casa_numerics::cell_noise`] gives the bounds and where they come
27//! from).
28//!
29//! # Where the draws come from
30//!
31//! CASA draws from one `MLCG` stream per term, in the order its visibility
32//! iterator visits rows, channels and correlations, and the stream carries on
33//! across `corrupt` calls. casa-rs keys each draw instead: the draws come
34//! from [`casa_numerics::cell_noise`] (Philox4x32-10 and Box–Muller in
35//! `f32`), whose counter is the absolute MAIN row, the channel and the
36//! correlation pair, and whose 64-bit key names the stream. This module
37//! forms the key ([`NoiseApplication`]): its first word is the term's seed
38//! (`sm.setseed`, as its 32 bits), and its second the purpose byte
39//! [`PURPOSE_THERMAL_NOISE`] above the term's application ordinal (how many
40//! `corrupt` calls the term had seen before). The two schemes are
41//! statistically equivalent, not bit-identical (plan, "Random numbers"), and
42//! they share the structure scripts see:
43//! - two terms with the same seed draw the same values in the same
44//!   `corrupt`, so their noise adds coherently (variance 4σ² for two);
45//! - one term applied twice draws independent values (variance 2σ²);
46//! - a different seed draws different values.
47//!
48//! The result depends only on (seed, ordinal, row, channel, correlation), so
49//! it is bitwise the same for any batch size, worker count, backend or
50//! platform; the tests hold a few cells to the bits they had before the
51//! generator moved to casa-numerics (#855).
52

56use casa_numerics::cell_noise::CellNoise;
57use num_complex::Complex32;
58
59/// The top byte of the key's second word names what the stream is for, so
60/// later corruptions (gains, fBM screens) draw from streams disjoint from
61/// thermal noise under the same seed.
62const PURPOSE_THERMAL_NOISE: u32 = 0x01;
63
64/// Application ordinals share the key word with the purpose byte, so a term
65/// can be applied at most this many times.
66pub(crate) const MAXIMUM_APPLICATIONS: u32 = 1 << 24;
67
68/// One application of a noise term: the noise one `corrupt` adds for one
69/// `setnoise` term.
70#[derive(Debug, Clone, Copy, PartialEq)]
71pub(crate) struct NoiseApplication {
72    /// The seed in force when the term was set (`sm.setseed`).
73    pub(crate) seed: i32,
74    /// σ of each real and imaginary draw, Jy, held as CASA holds it.
75    pub(crate) sigma_jy: f32,
76    /// How many times the term had been applied before; below
77    /// [`MAXIMUM_APPLICATIONS`].
78    pub(crate) ordinal: u32,
79}
80
81impl NoiseApplication {
82    /// The stream key: the seed's 32 bits (two's complement), then the
83    /// thermal-noise purpose byte above the ordinal.
84    fn key(&self) -> [u32; 2] {
85        debug_assert!(self.ordinal < MAXIMUM_APPLICATIONS);
86        [
87            self.seed as u32,
88            (PURPOSE_THERMAL_NOISE << 24) | self.ordinal,
89        ]
90    }
91
92    /// This application's noise: σ = `sigma_jy` under [`Self::key`].
93    pub(crate) fn noise(&self) -> CellNoise {
94        CellNoise::new(self.key(), self.sigma_jy)
95    }
96
97    /// Add this application's noise to the cell of MAIN row `row`:
98    /// `correlations × channels` samples, correlation fastest. An
99    /// autocorrelation row gets real draws only; samples past the last
100    /// whole channel are left alone ([`CellNoise::add_to_row`]).
101    pub(crate) fn add_to_row(
102        &self,
103        row: u64,
104        autocorrelation: bool,
105        correlations: usize,
106        cell: &mut [Complex32],
107    ) {
108        self.noise()
109            .add_to_row(row, autocorrelation, correlations, cell);
110    }
111}
