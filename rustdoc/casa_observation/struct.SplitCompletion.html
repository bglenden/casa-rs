Struct SplitCompletion 

Source 
pub struct SplitCompletion { /* private fields */ }
Expand description

The completion a TimeSplit’s traversals share: the joins of GroupCompletion over every slice, so that a group the cuts divide is ready once, after each part’s input has completed in its slice and all work begun on it has finished, however the slices interleave.

Each slice’s consumer works through its own SliceCompletion (Self::slice), which is Send; any one of them may finish a token another began. Whichever call makes a group ready returns true, once across the slices. A token dropped unfinished abandons its group, as with one traversal, and so does a slice’s view that ends (SliceCompletion::end) or is dropped while a part of the group it holds is open: a slice whose traversal failed is reported, not waited for. Such a slice is not run again within the split: its groups are abandoned, so a retry plans a fresh completion.

pub fn is_idle(&self) -> Result<bool, ObservationError>

Whether no work is pending, no closed group awaits its work and every divided group’s parts have all completed: true once every slice’s traversal is consumed and its work finished.

§Errors

ObservationError::WorkAbandoned if a unit of work was abandoned, or a slice ended with a part open.
