4//! The shared radio-interferometric measurement operator.
5//!
6//! This crate owns the forward operator `A` (model image to predicted
7//! visibilities) and its adjoint `A*` (weighted visibilities to unnormalised
8//! image-domain normal images) as one implementation parameterised by a
9//! convolution-function set ([`ConvolutionFunctionSet`]: the standard
10//! [`Spheroidal`] set here, W-planes, AW catalog and mosaic primary beam in
11//! later tickets) and a gridding backend ([`GridBackend`]: [`CpuBackend`]
12//! here; the Metal backend in `casa-imaging-metal` grids into
13//! [`GridStorage::Device`] cells). It also owns the global weighting generation
14//! ([`WeightingGeneration`]) and the spectral resampler that turns native
15//! rows into [`Placement`]s.
16//!
17//! The design is `docs/imaging-architecture/imaging-foundation-plan-20261007.md`
18//! section 5.3 and ADR-0016; ticket IF-1 (#650) filled this crate.
19//!
20//! # Conventions
21//!
22//! Grid and image planes are `[y][x]`, x fastest. Visibilities follow the
23//! MeasurementSet convention `V = ∫ I e^{+2πi(ul + vm)}`; the adjoint uses
24//! an unnormalised inverse FFT, so a source at direction cosines `(l, m)`
25//! lands on image pixel `(l/Δx, m/Δy)` from the reference pixel with the
26//! signed WCS increments. Values in a [`SampleBlock`] are pre-multiplied by
27//! the imaging weight and the phase-centre phasor `e^{iφ}`; prediction
28//! applies `e^{−iφ}`. The image correction is one real diagonal applied on
29//! both sides of the operator (CASA divides the model and the image by the
30//! same spheroidal response), so `A*` is the exact adjoint of `A` up to the
31//! polarization basis, whose image-domain conversion follows CASA's
32//! `StokesImageUtil` including its `1/2` factors and `sumwt` rule.
