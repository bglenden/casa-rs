One partition read as one batch per selected data group for each range of times: a traversal per group, each sized to the same whole times per batch, the first with first roles and every other with its visibilities only.

read
Read partition id of observation, every channel and product of each of groups, handing each one batch per group for each range of times, in time order. The batches hold whole times, budget bytes of them for all groups together, and a multiple of chunk times where that fits: the destination’s chunk, or with None the source’s natural time block, so that no unit is decoded twice.
