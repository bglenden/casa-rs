Regrid a complex AW convolution plane around its integer centre pixel, using CASA’s cubic interpolation separately on the real and imaginary parts (SynthesisUtils::rotateComplexArray). The matrix maps an output offset from that centre to the corresponding input offset. Pixels with no input sample are zero. The first axis is contiguous in both arrays.
