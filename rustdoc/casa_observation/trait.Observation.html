Expand description

An opened observation, whatever stores it.

This is the one interface algorithm code sees: the catalogue to plan from, Self::estimate to cost a batch shape before reading anything, and Self::bind_read for each traversal it needs. Choosing a backend and its storage options happens when the observation is opened, outside the algorithm; afterwards the algorithm handles only the Catalogue, AccessRequests, the bound Traversal and VisibilityBatch views. Dispatch to the store happens once per bind and once per batch, never per element.

fn bind_read( &self, request: &AccessRequest, ) -> Result<Traversal<'_>, ObservationError>

Bind a traversal of request: one cursor per requested partition, each Send, so threads can share the observation by reference and run partitions in parallel.

§Errors

When the request names something the observation does not have, asks for a role the store does not hold, needs a profile the store’s adapter does not implement, or budgets less than one time. Nothing has been read.

Source

fn grid( &self, id: PartitionId, data_group: &str, ) -> Result<TimeBaselineGrid, ObservationError>

The sample grid of partition id as data group data_group places it (its fields), for a producer to declare when it writes the partition elsewhere: from the store’s index, reading no payload.

§Errors

When the observation has no such partition or data group, or the partition is not one grid: no scan at each time, or acquisitions of more than one integration interval.

Source

fn group_keys( &self, id: PartitionId, data_group: &str, grouping: Grouping, ) -> Result<Option<Vec<GroupKey>>, ObservationError>

The scientific group of each of partition id’s grid times under grouping, as data group data_group places them (its fields), keyed as a traversal keys them (over the whole grid, whatever its time selection), or None when grouping asks for no groups: from the store’s index, reading no payload. A TimeSplit counts the groups its cuts divide from these.

§Errors

When the observation has no such partition or data group, or grouping cannot key its times (by scan, when the store names none; by a time bin that is not positive).
