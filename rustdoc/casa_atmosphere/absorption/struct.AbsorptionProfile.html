pub fn from_channels( atmosphere: AtmosphereProfile, grid: SpectralGrid, channels: Vec<C>, ) -> Result<Self, AtmosphereError>

A profile from channels computed elsewhere (for example in parallel with channel_absorption or channel_totals), one per grid channel in the grid’s flat order.

The profile keeps no spare capacity: the vector of channels (and the grid’s and atmosphere’s vectors) are shrunk to their lengths, so the profile keeps AbsorptionProfile::bytes however channels was grown. Shrinking reallocates in place where the allocator can; give an exactly sized vector to be sure of no transient copy.

§Errors

AtmosphereError::InvalidParameter if the channel count, a channel’s frequency or its layer count does not match grid and atmosphere.

Source

pub fn bytes(grid: &SpectralGrid, layers: usize) -> u64

The heap bytes a profile of this form keeps for grid and an atmosphere of layers layers: the vector of channels and each channel’s layers, the grid’s windows and channel frequencies, and the atmosphere’s layers. A profile keeps exactly this, whatever spare capacity the vectors it was built from had (see AbsorptionProfile::from_channels). Building with AbsorptionProfile::new or AbsorptionProfile::new_totals holds nothing more: the channels’ vector is allocated once at its size and each layer is formed in place. The allocation tests measure both.
